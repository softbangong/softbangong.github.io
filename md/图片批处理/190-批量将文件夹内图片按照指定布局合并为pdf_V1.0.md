图片批量合并为 PDF 工具，可自动识别文件夹（含子文件夹）内的所有图片，按自定义布局、分辨率、页面方向批量生成 A4 格式 PDF 文件，支持多种图片格式，操作简单且输出画质可自定义   

**▶功能特点：**   

支持  .jpg", ".jpeg", ".png", ".bmp", ".tif", ".tiff", ".webp", ".gif" 图片格式   

可自定义 PDF 页面方向（竖版 / 横版）、每页图片布局（自动 / 自定义行列）、输出分辨率（300-1200DPI）及 PDF 质量；   

支持处理子文件夹，每个文件夹单独生成对应 PDF，文件命名清晰；   

支持按照短边长边对图片旋转方向，确保 PDF 内图片显示正常；   

支持自定义 PDF 保存路径，也可默认保存至原文件夹，灵活便捷。

### 📑 使用场景例子展示   

#### 场景 1：批量整理照片文件夹为 PDF（自动布局）   

**场景描述：**电脑中有多个存放旅行照片的子文件夹，需要将每个文件夹内的照片单独合并为竖版 PDF，每页自动适配布局，分辨率设为 600DPI，高质量输出，方便归档查看。   

**操作步骤：**双击启动工具后，点击 “浏览” 选择存放照片的根文件夹，勾选 “穿透子文件夹”；   

页面方向选择 “竖版”，图片旋转选择 “宽度 < 高度时顺时针 90°”，分辨率选择 600DPI，PDF 质量选择 “高质量”，布局选择 “自动选择”；   

保存位置选择默认（原文件夹），点击 “开始合并为 PDF”；   

等待日志提示 “全部完成”，即可在每个照片子文件夹中找到生成的 PDF 文件，命名包含布局和页面方向信息。   

**预期结果：**每个照片文件夹都生成对应的 PDF 文件，照片按文件名自然排序，自动适配每页布局，图片显示正常无旋转错误，PDF 清晰度高，可直接打开查看或打印。   

#### 场景 2：自定义布局批量转换图片为横版 PDF   

**场景描述：**有一批产品展示图片，需要将其合并为横版 PDF，要求每页显示 3 行 3 列图片，分辨率设为 450DPI，标准质量输出，保存到指定文件夹便于分享。   

**操作步骤：**启动工具后，点击 “浏览” 选择产品图片所在文件夹（不勾选子文件夹）；   

页面方向选择 “横版”，图片旋转选择 “不旋转”，分辨率选择 450DPI，PDF 质量选择 “标准”，布局选择 “3 行 ×3 列”；   

勾选 “自定义保存位置”，点击 “浏览” 选择桌面作为保存路径，点击 “开始合并为 PDF”；   

等待日志提示处理完成，即可在桌面找到生成的 PDF 文件。   

**预期结果：**生成的横版 PDF 中，每页整齐显示 9 张产品图片，布局为 3×3，图片大小统一，文件体积适中，便于传输和分享。

### 常见问题解答（FAQ）   

**Q：工具无法启动，没有任何反应怎么办？**   

A：首先检查电脑系统是否为 Windows 7 及以上 64 位系统，32 位系统不支持该工具；其次确认工具压缩包是否解压完整，若文件不全，需重新下载并解压；最后检查电脑杀毒软件是否将工具误判为风险程序并拦截，将工具文件夹添加到杀毒软件信任列表后，重新启动工具。   

**Q：工具提示 “未找到任何包含图片的文件夹”，但文件夹内明明有图片怎么办？**   

A：先确认图片格式是否为工具支持的类型（JPG、PNG、BMP、TIFF、WEBP 等）；再检查是否勾选 “穿透子文件夹”，若图片在子文件夹中但未勾选该选项，工具仅扫描根文件夹；最后检查图片文件路径和名称是否含特殊字符，修改为纯英文 / 数字后重试。   

**Q：生成的 PDF 中图片显示旋转错误、方向颠倒怎么办？**   

A：重新启动工具，在 “图片旋转” 选项中选择对应策略（如 “宽度 < 高度时顺时针 90°”）；若仍有问题，可先手动调整图片的 EXIF 旋转信息，再重新处理；工具已内置自动旋转功能，若失效可检查图片是否损坏，更换完整的图片文件重试。   

**Q：生成的 PDF 文件过大，想要减小体积怎么办？**   

A：在工具中选择 “PDF 质量” 为 “标准”（而非高质量 / 最大质量），同时降低输出分辨率（如从 600DPI 改为 300DPI）；也可将图片分批处理，减少单份 PDF 中的图片数量；处理完成后，可使用 PDF 压缩工具二次压缩，进一步减小文件体积。   

**Q：工具运行中提示 “无法处理图片（已跳过）”，部分图片未生成到 PDF 中怎么办？**   

A：检查跳过的图片是否损坏（尝试用图片查看器打开），损坏的图片需替换为完整版本；若图片格式为工具不支持的类型（如 RAW 格式），需先转换为 JPG/PNG 格式；若图片路径过长或名称特殊，修改路径和名称后重新处理。
