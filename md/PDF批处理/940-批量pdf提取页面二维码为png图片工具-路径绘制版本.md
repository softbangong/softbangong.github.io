用于从 PDF 文件中批量提取页面中的二维码图片，只支持路径绘制识别提取。   

![](https://www.softbangong.com/wp-content/uploads/2026/05/image-5.png)   

## 功能特点   
- 自动提取 PDF 页面中的二维码区域并保存为高清 PNG 图片
- 基于 pdf 绘图形状（路径绘制）智能识别二维码位置，并提取保存到指定文件夹下
- 支持批量处理一个或多个 PDF 文件
- 支持拖拽单个 PDF 文件或文件夹到输入框
- 支持递归扫描子文件夹（包含子文件夹选项）
- 可为每个 PDF 自动创建同名文件夹存放二维码
- 高 DPI 自适应，在高分屏下显示清晰

## 使用方法   
1. **运行程序**
   
1. **选择 PDF 路径**
    - 点击”浏览文件”选择单个 PDF 或包含 PDF 的文件夹
    - 或直接拖拽 PDF 文件/文件夹到路径输入框
2. **设置选项（可选）**
    - ☐ 包含子文件夹 — 递归扫描子目录中的 PDF
    - ☐ 为每个PDF创建同名文件夹 — 二维码按 PDF 名称分目录存放
3. **选择输出目录**
    - 点击”浏览”选择保存二维码图片的文件夹
    - 或拖拽文件夹到输出目录输入框
4. **开始提取**
    - 点击”开始提取”按钮
    - 观察日志和进度条，支持随时点击”停止”中断
   

## 提取原理   

本工具通过分析 PDF 页面的**绘图形状**定位二维码区域：   
- 扫描 PDF 页面的数据
- 筛选无颜色的绘图形状作为二维码候选
- 按成对形状定位二维码在页面中的裁剪区域
   

## 注意事项   
- 提取效果取决于 PDF 中二维码的绘图数据结构，部分 PDF 需手动测试
   

**注意：**不同文件夹下序号为连续的
