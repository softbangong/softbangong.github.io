可视化的视频批量处理工具，主打视频尺寸调整、自定义文本添加、背景样式设置等核心功能。无需专业视频编辑技能，即可完成视频分辨率比例适配、文本层自定义（标题 / 内容双文本）、背景（纯色 / 图片）设置，支持批量处理、可视化预览、配置保存 / 导入，适配 mp4、avi、mkv、mov 等主流视频格式，适合自媒体、办公场景下的视频批量标准化处理。   

![](https://www.softbangong.com/wp-content/uploads/2026/04/20251129110603176438556359749.jpg)   

### 功能亮点   

**拖放/批量导入**：直接把多个视频拖入列表，支持逐条或批量配置。   

**多比例画布**：内置 16:9、9:16、4:3、1:1、18:9、21:9、4:5、3:4 等主流比例，可随时切换。   

**背景自定义**：支持预设纯色（黑 / 白 / 红 / 蓝 / 绿）、自定义 RGB 颜色、背景图片（PNG/JPG/BMP/GIF），满足不同视觉需求；   

**文本精细化编辑**：   

标题 / 内容双文本层独立配置，支持自定义字体（TTF/TTC/OTF）、大小（10-200）、颜色；   

文本可拖拽移动、缩放，右键菜单支持左 / 中 / 右、上 / 中 / 下对齐，行间距调整；   

文本内容双击可直接编辑，实时同步到配置；   

**实时/手动预览**：可勾选“实时预览”自动刷新，也可手动点击“更新预览效果”生成一次静态图。   

**配置管理**：随时保存/导入 JSON 配置（包含文本位置、颜色、字体、背景等），便于复用模板。   

输出路径默认为 `{原文件名}_调整.{扩展名}`，存放在源文件同目录。   

### 使用场景例子展示   

**场景 1：批量制作 9:16 竖屏短视频（抖音 / 快手适配）**   

**需求**：将 10 个 16:9 横屏 MP4 视频转为 9:16 竖屏，黑色背景，视频居中显示，添加白色标题 “产品开箱”（字体大小 60，微软雅黑），内容文本 “点击查看详情”（字体大小 30，白色），右对齐。   

**操作步骤**：   

拖放 10 个视频到列表，选中第一个视频；   

比例选择 “9:16”，对齐方式 “垂直居中对齐”，背景选 “黑色”；   

标题输入 “产品开箱”，大小 60，颜色白色，点击 “选择字体” 也可以不选择，使用默认字体；   

内容输入 “点击查看详情”，大小 30，颜色白色；   

预览区域右键添加标题 / 内容文本，右键文本选择 “右对齐”，调整行间距为 “大”；   

点击 “应用到所有视频”，保存配置为 “竖屏短视频配置.json”；   

点击 “更新预览效果” 确认，点击 “开始处理”；   

**预期结果**：所有视频转为 9:16 竖屏，黑色背景，视频居中，右侧显示白色标题和内容，行间距增大，输出文件保存在原目录。   

**场景 2：批量添加品牌水印（1:1 方形视频）**   

**需求**：将 5 个 MOV 视频转为 1:1 方形，背景用品牌 LOGO 图片（透明 PNG），添加红色品牌名 “XX 科技”（字体大小 48，居中对齐），批量处理。   

**操作步骤**：   

添加 5 个 MOV 视频到列表，选中第一个；   

比例选择 “1:1”，对齐方式 “垂直底部对齐”；   

点击 “选择图片”，选品牌 LOGO PNG 文件；   

标题输入 “XX 科技”，大小 48，颜色红色，默认宋体；   

预览区域右键添加标题文本，选择 “居中对齐”；   

点击 “应用到所有视频”，点击 “开始处理”；   

**预期结果**：视频转为 1:1 方形，背景为 LOGO，视频底部对齐，居中显示红色品牌名，保留原视频音频。   

### 可视化编辑说明   

点击 “更新预览效果”，生成视频第一帧预览背景；   

预览区域右键，选择 “添加标题文本 / 添加内容文本”，生成可交互文本框；   

文本框操作：   

拖拽：按住左键拖动，调整文本位置；   

缩放：拖动文本框右下角手柄，调整字体大小；   

编辑内容：双击文本框，直接修改文字（失去焦点后同步到输入框）；   

右键菜单：支持对齐（左 / 中 / 右、上 / 中 / 下）、颜色设置、行间距（默认 / 大）。   

### 批量配置   

**应用到所有视频**：编辑好单个视频配置后，点击该按钮，将当前配置同步到列表所有视频；   

**保存配置**：点击 “保存配置”，将所有视频的配置保存为 JSON 文件（含路径、分辨率、文本、背景等），方便后续复用；   

**导入配置**：点击 “导入配置”，选择之前保存的 JSON 文件，自动加载视频列表和对应配置（无效路径会自动忽略）。

### 注意事项   

**文本设置**：   

文本含特殊字符（单引号、冒号）时，工具自动转义，无需手动处理；   

自定义字体路径避免含空格 / 中文特殊字符；   

**背景图片**：   

背景图片分辨率建议与目标视频比例一致，避免拉伸变形；   

透明 PNG 背景可正常使用；   

**路径要求**：   

视频 / 背景 / 字体文件路径需为纯英文 / 数字，避免中文特殊字符（如 “#、@、空格”）；   

**预览限制**：   

预览仅生成视频第一帧效果，若视频开头无画面，以最终处理结果为准；   

**异常处理**：   

工具崩溃时，已处理的视频不会丢失，未处理的可重新加载配置处理；   

若文本不显示，检查文本颜色与背景色是否一致、字体大小是否过小。   

### 常见问题解答（FAQ）   

**Q2：添加文本后预览 / 处理后视频无文本？**   

A：1. 检查文本内容是否为空、字体大小是否≥10；  
2. 自定义字体加载失败（日志提示 “字体文件无有效字体族”），更换宋体 / 微软雅黑重试；  
3. 文本颜色与背景色一致（如白色文本 + 白色背景），修改文本颜色；   

**Q3：处理后的视频画面变形？**   

A：1. 确认比例选择正确（如横屏视频选 9:16 会拉伸，建议先裁剪）；  
2. 背景图片分辨率与目标视频比例不一致，更换匹配比例的图片；   

**Q4：预览区域右键无法添加文本？**   

A：1. 需先选中列表中的视频文件，再点击 “更新预览效果” 生成背景；  
2. 重启工具，排除界面卡顿；  
3. 检查视频文件是否损坏（用播放器打开验证）。   

**Q5：批量处理部分视频失败？**   

A：1. 失败视频路径含特殊字符，修改路径为纯英文；  
2. 视频被其他程序占用（如播放器未关闭），关闭后重试；  
3. 视频编码不被 FFmpeg 支持，转换为 MP4 后再处理。
