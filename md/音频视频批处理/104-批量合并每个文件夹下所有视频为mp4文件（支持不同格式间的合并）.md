## 104-批量合并每个文件夹下所有视频为mp4文件（支持不同格式间的合并）   

批量合并不同格式的视频为mp4文件   

支持的文件格式：'.avi', '.mp4', '.mov', '.wmv', '.flv', '.mkv', '.ts', '.webm', '.m4v', '.asf'   

**支持子文件夹穿透**，不同文件夹下视频分别进行合并，   

A文件夹下视频合并后保存在A文件夹下，合并后的文件名：A_merged.mp4   

如果视频文件尺寸不同会自动调整为相同尺寸，不足的部分会自动使用虚化模糊背景填充   

| **▶子文件夹穿透：**支持 |
| -------------- |
| **▶支持的文件格式：**'.avi', '.mp4', '.mov', '.wmv', '.flv', '.mkv', '.ts', '.webm', '.m4v', '.asf' |
| **▶支持的文件格式：**'.avi', '.mp4', '.mov', '.wmv', '.flv', '.mkv', '.ts', '.webm', '.m4v', '.asf' |
