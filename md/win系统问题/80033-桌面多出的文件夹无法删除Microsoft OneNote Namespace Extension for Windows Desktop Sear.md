桌面多出的文件夹无法删除Microsoft OneNote Namespace Extension for Windows Desktop Search，9层把握使用下方方式可以解决。   

![](https://www.softbangong.com/wp-content/uploads/2026/04/20250301231038174084183871528.png)   

1、打开注册表（在“运行”里，输入duregedit），  
2、找到zhihkey_local_machine\software\microsoft\windows\currentversion\explorer\desktop\namespace\  
3、然后点击列表文件夹找到一个文件夹，右面的显示是Microsoft OneNote Namespace Extension for Windows Desktop Search，将这个值删除即可
