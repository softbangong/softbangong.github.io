在 Python 中删除虚拟环境可以通过直接删除其所在的文件夹来实现   

### **直接删除文件夹（适用于大多数情况）​**   

虚拟环境的本质是一个包含独立 Python 解释器和依赖包的文件夹（如 `venv/` 或 `.venv/`）。​​直接删除该文件夹即可彻底移除虚拟环境，比如创建的是如下文件夹类型，前提是你知道哪个是你创建的虚拟环境所在文件夹   

![](https://www.softbangong.com/wp-content/uploads/2026/04/20250428230037174585243729410.png)   

### **注意事项​**   

#### **确保虚拟环境未激活​**   

**不要在激活状态下删除​​：如果当前终端已激活该虚拟环境（显示 `(venv)`），需要先退出虚拟环境，然后再删除**
