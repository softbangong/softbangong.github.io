# 弹窗广告位 — Z-BlogPHP 弹窗广告插件   

> 为 Z-BlogPHP 网站提供 PC 端与移动端独立的弹窗广告位，支持 HTML 与文本双模式内容渲染，内置关闭 Cookie 定时隐藏机制与自定义 CSS 样式，帮助站长灵活投放广告与公告。
   

**版本**：v2.1.4  
**适配**：Z-BlogPHP 1.7.0+  
**PHP**：>= 7.2  
**作者**：softbangong  
**授权**：不限制网站数量，下载安装后永久免费使用   

## 插件简介   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-12.png)   

本插件用于在 Z-BlogPHP 网站前台展示弹窗广告或公告内容，无需修改主题模板即可快速部署。插件在页面加载时自动注入弹窗 HTML 与样式脚本，通过 UA 检测自动区分 PC 端与移动端，分别加载对应的弹窗配置，确保在不同设备上都能获得合适的展示效果。   

插件提供 HTML 模式与文本模式两种内容渲染方式：HTML 模式自动过滤 script 标签与事件属性，仅渲染安全的 HTML 内容；文本模式对所有输入进行 HTML 转义并采用公告风格展示，适合发布网站通知或声明。   

用户点击关闭按钮后，插件通过 Cookie 记录关闭状态，在设定的时间范围内不再弹出，避免反复打扰访客。Cookie 有效期支持 1 秒至 86400 秒（24 小时）自由调节。   

## 功能特性   

### PC 端与移动端独立弹窗   

插件为 PC 端和移动端各提供 3 个弹窗位置，共 6 个独立弹窗位，每个位置可分别配置内容与开关：   

| 端 | 位置 | 说明 |
| --- | --- | --- |
| PC 端 | 中间弹窗 | 页面中央弹出，适合重要公告或大型广告 |
| PC 端 | 左下角弹窗 | 页面左下角固定，适合轻量提示或小尺寸广告 |
| PC 端 | 右下角弹窗 | 页面右下角固定，适合客服引导或二维码推广 |
| 移动端 | 中间弹窗（移动） | 移动端页面中央弹出，自适应屏幕宽度 |
| 移动端 | 左下角弹窗（移动） | 移动端左下角固定，适合轻量提示 |
| 移动端 | 左下角弹窗（移动） | 移动端左下角固定，适合轻量提示 |
   

插件通过 User-Agent 自动识别访客设备类型，无需手动配置即可为不同设备加载对应的弹窗配置。   

### HTML 与文本双模式   

每个弹窗位支持两种内容模式，可根据需求灵活选择：   

— **HTML 模式**：直接渲染 HTML 内容，插件自动过滤 script 标签、onclick 等事件属性以及 javascript: 伪协议链接，确保安全性；  
— **文本模式**：对所有输入内容进行 HTML 转义后渲染，采用公告风格界面展示，包含标题栏和正文区域，适合发布网站通知或声明。   

### 关闭 Cookie 定时隐藏   

用户点击弹窗关闭按钮后，插件通过 Cookie 记录该弹窗的关闭状态：   

— 在设定的秒数（1 至 86400 秒）内，同一浏览器不再重复弹出该弹窗；  
— 每个弹窗位的 Cookie 独立管理，关闭 A 弹窗不影响 B 弹窗的展示；  
— 支持同时展示多个已启用的弹窗，互不干扰。   

### 自定义 CSS 样式   

插件后台提供自定义 CSS 输入框，可直接编写样式覆盖弹窗默认外观。建议使用 `.tcad-` 前缀选择器限定作用域，避免影响网站其他元素。插件会在前台页面自动注入自定义样式，无需手动修改模板文件。   

### 每个弹窗独立配置   

每个弹窗位均支持以下独立设置：   

— **启用开关**：一键开启或关闭该弹窗位；  
— **内容模式**：HTML 模式或文本模式自由切换；  
— **标题**：自定义弹窗标题文字（文本模式下显示在标题栏）；  
— **宽度与高度**：支持 px、em、rem、%、vw、vh 等 CSS 单位，留空则使用默认尺寸；  
— **水印文字**：弹窗角落显示广告标识文字（如”广告”），可独立控制显示或隐藏。   

### 中英文双语后台   

插件后台管理界面支持中文和英文切换，所有字段标签、提示文字和按钮文本均随语言设置动态切换，方便不同语言习惯的站长使用。   

### 卸载配置可控   

插件卸载时，用户可在后台设置中选择清空所有配置数据或保留配置。选择保留时，重新安装插件后将自动恢复之前的弹窗设置。   

### 响应式自适应   

弹窗样式针对移动端进行了响应式适配，在小屏幕设备上自动缩小弹窗尺寸，确保内容不被遮挡且关闭按钮始终可点击。文本模式弹窗在移动端自动降低正文字号和最大高度。   

## 使用说明   

### 第一步：安装插件   

将 `tcad_tanchuang` 文件夹上传至网站 `zb_users/plugin/` 目录，进入 Z-BlogPHP 后台「插件管理」页面，找到「弹窗广告位」并点击启用。   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-13.png)   

### 第二步：配置弹窗内容   

进入后台顶部菜单「弹窗广告位」或「插件管理 → 弹窗广告位 → 设置」：   

— 在「全局设置」卡片中设置语言、关闭后隐藏秒数、水印文字、自定义 CSS 等全局参数；  
— 在「PC 端弹窗广告」卡片中分别配置中间、左下角、右下角三个弹窗位的内容和开关；  
— 在「移动端弹窗广告」卡片中分别配置移动端的三个弹窗位，如需在移动端展示相同的弹窗内容，可参考 PC 端配置同步填写；  
— 每个弹窗位可独立选择 HTML 或文本模式，设置标题、宽高和水印显示状态；  
— 如某个位置不需要弹窗，将启用开关关闭即可。   

### 第三步：提交保存   

点击页面底部的「提交」按钮保存所有配置。插件会将配置同时写入 Z-BlogPHP 数据库和 `config.json` 文件，确保数据不丢失。   

### 第四步：前台验证   

— 使用 PC 浏览器访问网站前台，检查配置的弹窗是否正常显示在对应位置；  
— 使用移动设备或浏览器移动端模拟模式访问，确认移动端弹窗是否正确加载；  
— 点击弹窗关闭按钮后刷新页面，验证弹窗是否在设定时间内不再出现；  
— 如有自定义 CSS，检查样式是否按预期生效。   

## 注意事项   

— 插件在前台注入弹窗时会自动加载所需的 CSS 和 JS 文件，如网站使用了 CDN 或缓存插件，修改弹窗配置后建议清除缓存以确保最新内容生效；  
— HTML 模式下插件会自动过滤 script 标签和事件属性，如需嵌入复杂交互内容，建议使用文本模式配合纯 HTML 样式实现；  
— 关闭 Cookie 的有效期最大为 86400 秒（24 小时），如需更长的隐藏时间，请在 Cookie 有效期内不要清除浏览器 Cookie；  
— 自定义 CSS 建议使用 `.tcad-` 前缀选择器编写，插件内置样式均使用该前缀以确保作用域隔离；  
— 移动端弹窗的宽高设置应与 PC 端区分（如 PC 端中间弹窗设置 600px 宽度，移动端建议设置 90vw 或更小），避免在小屏幕上内容溢出。
