# 静态管理中心 — Z-BlogPHP 伪静态插件   

> 将 Z-BlogPHP 文章、页面、分类、标签、作者、日期归档等页面的动态 URL 转换为伪静态格式，提升搜索引擎友好度。内置 301 自动重定向，兼容 Apache / Nginx / IIS / Lighttpd 主流服务器。
   

**版本**：v3.10  
**适配**：Z-BlogPHP 1.7.0+  
**PHP**：≥ 7.2  
**作者**：softbangong  
**授权**：不限制网站数量，下载安装后永久免费使用   

![zblog静态管理中心](https://www.softbangong.com/wp-content/uploads/2026/07/image.png)   

## 插件简介   

本插件用于管理 Z-BlogPHP 网站的 URL 伪静态规则，将原本带问号参数（如 `/?id=123`）的动态链接，重写为搜索引擎和访客更容易识别、记忆的静态格式链接（如 `/post/123.html`）。   

插件在后台提供了集中化的配置管理界面，支持三种 URL 模式一键切换、每种页面类型单独配置规则、实时预览最终 URL 效果，并且可根据中文站或英文站给出不同的 SEO 评分作为参考，帮助您快速选择最优方案。   

同时，插件在 PHP 层面自动实现了 301 永久重定向：当访客或搜索引擎通过旧的动态链接访问时，会自动跳转到对应的新静态地址，防止出现重复内容，利于 SEO 收录和排名。   

## 功能特性   

### 三种 URL 模式，一键切换   

| 模式 | URL 示例 | 说明 |
| --- | ------ | --- |
| 动态模式 | `/?id=123` | 原始动态链接，无需服务器 Rewrite 组件 |
| index.php 式伪静态 | `/index.php/post/123.html` | Apache / IIS 下无需额外配置 Rewrite 规则即可使用 |
| index.php 式伪静态 | `/index.php/post/123.html` | Apache / IIS 下无需额外配置 Rewrite 规则即可使用 |
   

您可以随时在三种模式之间切换。切换到动态模式时，插件会自动清除之前生成的 `.htaccess` 规则，保留您自行添加的自定义内容。   

### 智能 SEO 评分   

每种 URL 规则模板都会显示 1 到 5 星的 SEO 评分，您可以直观地比较不同规则的优劣：   

— **中文站**优先推荐纯数字 ID 的 URL（如 `/post/123.html`），对百度等国内搜索引擎更友好，URL 简洁稳定；  
— **英文站**优先推荐含关键词别名的 URL（如 `/post/hello-world.html`），对 Google 等搜索引擎更友好，URL 语义丰富；  
— 插件后台提供「中文站 / 英文站」一键切换按钮，切换后所有评分和推荐规则会即时更新，同时自动为您重选当前语言下的最优预设。   

### 301 自动重定向   

插件在 PHP 层自动实现了 301 永久重定向功能，启用后无需任何额外配置即可生效：   

— 旧动态链接（如 `/?id=123`）被访问时，自动 301 跳转到您配置的新静态地址（如 `/post/123.html`）；  
— 自动识别旧 `/index.php/post/123.html` 等格式的链接并跳转到当前配置的静态 URL；  
— 内置循环检测机制：如果当前请求的 URL 已经是目标地址，则跳过跳转，不会产生无限重定向；  
— 自动排除管理后台路径（`/zb_system/`、`/zb_install/`、`/zb_users/`），确保后台功能不受影响。   

此外，Apache 用户还可以在「ReWrite规则」页面追加服务器层的 301 规则，让重定向在 PHP 运行之前由 Apache 完成，进一步提升性能。   

### 多服务器 Rewrite 规则生成   

插件支持主流 Web 服务器的规则配置，可在后台自动生成对应格式的配置文件：   

— **Apache .htaccess**：自动生成三个独立区块 —— Rewrite 重写规则、301 重定向规则、旧链接跳转规则。每个区块可单独生成、更新或清除，不覆盖您已有的自定义规则；  
— **IIS 7+ web.config**：适用于安装了微软官方 URL Rewrite Module 的 IIS 7 及以上版本；  
— **IIS 6 httpd.ini**：适用于安装了 ISAPI Rewrite 组件的 IIS 6；  
— **Nginx 配置**：生成可直接放入 server 或 location 节点的配置规则；  
— **Lighttpd 配置**：生成 lighttpd.conf 格式的伪静态规则。   

所有规则均支持一键生成配置文件到网站根目录，也支持手动复制粘贴。   

### 实时 URL 预览   

在配置页面修改任何 URL 规则或切换模式时，页面底部会即时显示该规则对应的最终 URL 效果。例如选择文章规则为 `{%host%}post/{%id%}.html` 时，预览区会立即显示 `https://www.example.com/post/123.html`，所见即所得，方便您确认规则是否正确。   

### 页面类型全覆盖   

插件支持 Z-BlogPHP 以下页面类型的 URL 规则配置，每种类型都有独立的输入框和预设选项：   

| 类型 | 可用变量 |
| --- | ---- |
| 文章页 | `{%host%}` `{%id%}` `{%alias%}` `{%year%}` `{%month%}` |
| 页面 | `{%host%}` `{%id%}` `{%alias%}` |
| 首页分页 | `{%host%}` `{%page%}` |
| 分类页 | `{%host%}` `{%id%}` `{%alias%}` `{%page%}` |
| 标签页 | `{%host%}` `{%id%}` `{%alias%}` `{%page%}` |
| 日期归档 | `{%host%}` `{%date%}` `{%page%}` |
| 日期归档 | `{%host%}` `{%date%}` `{%page%}` |
   

### 管理后台安全保护   

— 自动排除 Z-BlogPHP 管理后台路径（`/zb_system/`、`/zb_install/`、`/zb_users/`），Rewrite 规则不会影响后台登录、设置、应用中心等页面的正常访问；  
— 切换回动态模式时，自动清除插件生成的 `.htaccess` 相关规则区块，保留您自行添加的自定义内容。   

## 使用说明   

### 第一步：安装插件   

将 `wjt_jingtai` 文件夹上传至网站 `zb_users/plugin/` 目录，进入 Z-BlogPHP 后台「插件管理」页面，找到「静态管理中心」并点击启用。   

### 第二步：配置 URL 规则   

进入后台「插件管理 → 静态管理中心 → 配置页面」：   

— 选择静态化模式：页面顶部提供「动态模式」「伪静态模式」「index.php 式伪静态」三个选项，点击即可切换；  
— 为每种页面类型选择或自定义 URL 规则：每种类型都有一个文本输入框和一组预设选项（如文章页提供 6 种预设规则），点击预设即可自动填入；  
— 每条预设规则右侧显示 SEO 星级评分（1-5 星）和对应的效果预览 URL，帮助您快速判断；  
— 页面底部实时显示当前规则的预览 URL，确认无误后点击提交。   

如果您不确定如何选择，推荐点击「一键伪静态」快捷卡片，插件会根据当前站点语言（中文站 / 英文站）自动为每种页面类型选出评分最高的规则，保存确认后自动跳转到规则生成页面。   

![zblog静态管理中心](https://www.softbangong.com/wp-content/uploads/2026/07/后台页面截图1-scaled.png)   

### 第三步：生成 Rewrite 规则（纯伪静态模式）   

如果您选择了纯伪静态模式，需要生成对应的服务器规则文件。进入「静态管理中心 → ReWrite规则」页面：   

— 页面顶部会根据您的服务器类型自动选中对应的 Tab（Apache / IIS / Nginx / Lighttpd）；  
— 查看自动生成的规则内容，确认无误后点击「创建 / 更新」按钮一键生成配置文件；  
— Apache 用户还可以分别追加「301 重定向规则」和「旧链接跳转规则」，两个规则区块独立管理，互不干扰。   

![zblog静态管理中心](https://www.softbangong.com/wp-content/uploads/2026/07/后台页面截图2.png)   

### 第四步：验证生效   

— 访问网站前台任意文章或分类页面，检查浏览器地址栏 URL 是否已变为静态格式；  
— 用旧的动态链接（如 `/?id=123`）测试访问，确认是否自动 301 跳转到新的静态地址；  
— 进入后台配置页面，状态栏会实时显示当前模式和规则文件状态。   

## 注意事项   

— 本插件实现的是伪静态（URL 重写），并非生成纯静态 HTML 文件，页面数据仍然由 Z-BlogPHP 动态输出；  
— 纯伪静态模式需要主机开启 Rewrite 模块。Apache 需要 `mod_rewrite`，IIS 7+ 需要安装 URL Rewrite Module（微软官方免费组件），IIS 6 需要 ISAPI Rewrite 组件；  
— index.php 式伪静态不需要服务器 Rewrite 支持，Apache 和 IIS 用户可以直接使用，适合虚拟主机等无法自主配置 Rewrite 的环境；  
— 网站安装在子目录时，生成的 Rewrite 规则可能需要手动微调路径前缀；  
— 切换模式后，如果前台页面仍显示旧的 URL 格式，建议清除浏览器缓存后重新测试。
