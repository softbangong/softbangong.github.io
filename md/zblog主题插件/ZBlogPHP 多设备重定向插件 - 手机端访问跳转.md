# 手机端访问跳转 — Z-BlogPHP 多设备重定向插件   

> 根据访问设备类型自动将访客 301 重定向到不同 URL，支持手机、平板、微信内置浏览器等 21 种预设设备，可按优先级从上到下依次匹配，精准控制每种设备的跳转目标。
   

**版本**：v1.0.0  
**适配**：Z-BlogPHP 1.7.0+  
**PHP**：>= 7.2  
**作者**：softbangong  
**授权**：不限制网站数量，下载安装后永久免费使用   

## 插件简介   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-9.png)   

本插件用于根据访客的设备类型自动执行 301 永久重定向，将不同设备的访客引导至对应的目标 URL。典型应用场景包括：将手机用户跳转到移动版网站、将微信内置浏览器用户跳转到微信专用页面、将腾讯系客户端用户跳转到适配页面等。   

插件内置了 21 种常见设备的预设规则，涵盖微信、QQ、腾讯系客户端、UC 浏览器、百度浏览器、搜狗浏览器、手机浏览器、平板设备、Opera、Firefox、Edge 以及主流国产手机厂商浏览器（小米、华为、Vivo、OPPO、三星）。每种规则可独立启用并配置跳转目标 URL，支持自定义 UA 检测关键词。   

检测采用从上到下的优先级机制，命中第一条匹配规则后立即执行跳转，后续规则不再检测。后台管理页面和插件自身页面自动排除，不会影响正常管理操作。

### 微信 / QQ 严格匹配   

微信内置浏览器和 QQ 内置浏览器采用严格匹配策略，仅匹配 UA 中明确包含 `MicroMessenger` 或 `QQ/` 标识的请求，避免将普通手机浏览器误判为微信或 QQ 客户端。插件后台界面中这两项规则会标注”严格匹配”，UA 关键词输入框也单独锁定，不可随意修改。   

### 腾讯系全覆盖   

插件内置了从微信到 QQ 空间的完整腾讯生态链检测规则：   

- 微信内置浏览器（MicroMessenger）：微信内打开链接时触发  
- QQ 内置浏览器（QQ/）：QQ 内打开链接时触发  
- QQ 浏览器（MQQBrowser、QQBrowser）：使用 QQ 浏览器 App 时触发  
- 腾讯客户端（TencentTraveler、QQGameHall 等）：覆盖腾讯新闻、腾讯视频、应用宝等客户端  
- QQ 空间客户端（Qzone/）：QQ 空间内打开链接时触发   

这五条规则从上到下排列，保证微信和 QQ 优先匹配，可分别配置不同的跳转目标。   

### 自定义设备规则   

除了 21 种预设设备规则，您还可以添加自定义设备类型：   

- 自定义设备名称，便于后台识别管理  
- 自定义 UA 检测关键词，支持 `|` 竖线分隔多个关键词（如 `MyApp|MyBrowser`）  
- 自定义跳转目标 URL  
- 自定义规则与预设规则混合排序，统一管理   

### 按优先级从上到下检测   

所有规则（预设 + 自定义）在同一表格中从上到下排列，检测时按此顺序依次匹配：   

- 命中第一条启用且 URL 不为空的规则后立即执行 301 跳转，后续规则不再检测  
- 可通过调整规则顺序来控制检测优先级，例如将微信规则放在最前面，确保微信访客优先匹配  
- 未启用或未填写跳转 URL 的规则会被自动跳过   

### 301 永久重定向   

插件在 PHP 层面执行 301 永久重定向，对搜索引擎友好，不会损失已有页面的收录权重。命中规则后立即发送 301 状态码并跳转，不经过 JavaScript 中转，无需前端脚本支持。   

### 后台管理页面保护   

插件自动排除 Z-BlogPHP 管理后台路径（`/zb_system/`、`/zb_users/plugin/`）以及插件自身的配置页面，确保后台管理操作不受跳转规则影响，避免出现登录后又被跳走的尴尬情况。   

### 后台菜单开关   

插件提供「添加到顶部菜单」开关，关闭后不在 Z-BlogPHP 后台左侧导航栏显示本插件入口。适合已配置好规则不再需要频繁修改的场景，保持后台菜单整洁。   

### 卸载时清空数据   

提供「卸载时清空数据」开关，开启后卸载插件时会自动删除插件配置数据（包括设备规则、菜单开关状态等），避免残留无用数据。默认关闭，保护配置数据不被误删。   

## 使用说明   

### 第一步：安装插件   

将 `mobile_redirect` 文件夹上传至网站 `zb_users/plugin/` 目录，进入 Z-BlogPHP 后台「插件管理」页面，找到「手机端访问跳转」并点击启用。   

### 第二步：配置跳转规则   

进入后台「插件管理 — 手机端访问跳转 — 设置」页面：   

- 在设备规则表格中，找到需要启用的设备类型，勾选右侧「启用」复选框  
- 在对应行的「跳转目标 URL」输入框中填写跳转地址（如 `https://m.example.com`）  
- 如需添加自定义设备，可在表格末尾新增行，填写设备名称、UA 关键词和跳转 URL  
- UA 关键词支持 `|` 竖线分隔多个关键词，系统会自动构建正则匹配  
- 点击「保存设置」按钮保存配置   

### 第三步：验证跳转效果   

- 用对应设备（如手机浏览器、微信内置浏览器）访问网站前台任意页面  
- 确认是否自动跳转到配置的目标 URL  
- 检查浏览器地址栏或开发者工具 Network 面板，确认返回的是 301 状态码  
- 访问后台管理页面，确认不会被跳转规则影响   

## 注意事项   

- 插件执行的是 301 永久重定向，浏览器和搜索引擎会缓存跳转关系。修改规则后建议清除浏览器缓存后重新测试  
- 跳转仅在 PHP 层面执行，访客必须正常访问网站 PHP 页面才会触发检测，不适用于纯静态 HTML 文件  
- 检测规则按表格中从上到下的顺序执行，请确保优先级高的规则排在前面  
- 微信（MicroMessenger）和 QQ（QQ/）采用严格匹配，UA 关键词已预设且不宜修改，避免误判  
- 后台管理页面（`/zb_system/`、`/zb_users/plugin/`）自动排除，确保后台操作不受影响  
- 每条规则都需要同时填写 UA 关键词和跳转 URL 并开启启用开关，三者缺一则跳过不执行  
- 旧版本（v1.0 之前）的简单模式配置数据会在首次访问后台时自动迁移到新规则格式
