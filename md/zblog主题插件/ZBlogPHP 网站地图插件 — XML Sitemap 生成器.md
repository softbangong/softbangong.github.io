# XML Sitemap 生成器 — Z-BlogPHP 网站地图插件   

> 自动生成标准 XML Sitemap 网站地图文件，支持单文件、按类型、按分类三种拆分模式。发布文章自动更新，定时重建保证时效性，帮助搜索引擎高效抓取和收录网站所有页面。
   

**版本**：v1.0.0  
**适配**：Z-BlogPHP 1.7.0+  
**PHP**：≥ 7.2  
**作者**：softbangong  
**授权**：不限制网站数量，下载安装后永久免费使用   

## 插件简介   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-10.png)   

本插件用于自动生成符合 sitemaps.org 协议的 XML Sitemap 网站地图文件，将网站首页、分类、标签、文章、页面等链接以标准 XML 格式输出，方便搜索引擎蜘蛛（Google、Bing、百度等）快速发现和抓取网站所有页面。   

插件在后台提供集中化的配置管理界面，支持选择不同的 Sitemap 拆分策略、为每种内容类型单独设置更新频率和优先级、一键手动生成，并可查看已生成文件的列表与详情。同时，插件在前台以访客请求触发的方式实现定时自动重建，无需配置计划任务（Cron），开箱即用。   

## 功能特性   

### 三种拆分模式   

| 模式 | 生成文件 | 适用场景 |
| --- | ---- | ---- |
| 单文件模式 | 所有 URL 合并到一个 `sitemap.xml` | 小型站点，URL 总数较少 |
| 按类型拆分 | 首页 / 分类 / 标签 / 文章 / 页面各一个独立 XML 文件 + 索引文件 | 中型站点，推荐方案 |
| 按类型拆分 | 首页 / 分类 / 标签 / 文章 / 页面各一个独立 XML 文件 + 索引文件 | 中型站点，推荐方案 |
   

按类型拆分模式下，插件自动生成一个 Sitemap 索引文件（sitemapindex），汇总指向各子文件的链接，搜索引擎通过索引即可发现所有子地图。按分类拆分模式下，每个分类的文章生成独立文件，方便大型站点分块管理和增量更新。   

### 自动生成机制   

插件提供两种自动生成触发方式：   

- **发布文章自动更新**：当您在后台发布或更新文章、页面时，插件自动重新生成 Sitemap 文件，确保地图内容与网站实际页面实时同步；  
- **定时自动重建**：通过访客请求触发，按设定的间隔天数自动重建 Sitemap。当前端有访客访问时，插件检查上次生成时间，若超过间隔天数则自动触发一次重建。无需服务器 Cron 支持，间隔灵活可配（0 到 365 天）。   

两种机制可同时启用或单独控制，满足不同更新频率的需求。   

### 内容类型全覆盖   

插件支持 Z-BlogPHP 以下内容类型的 Sitemap 收录，每种类型可独立开关：   

| 类型 | 说明 |
| --- | --- |
| 首页 | 网站首页链接 |
| 分类 | 全部分类页面链接 |
| 标签 | 全部标签页面链接 |
| 文章 | 所有已发布文章链接 |
| 文章 | 所有已发布文章链接 |
   

每种内容类型可单独设置是否包含在 Sitemap 中，未被勾选的类型不会出现在生成的 XML 文件中。   

### 自定义更新频率和优先级   

每种内容类型支持独立设置以下 Sitemap 标准参数：   

- **更新频率（changefreq）**：可选 总是 / 每小时 / 每天 / 每周 / 每月 / 每年 / 从不，告知搜索引擎该类型页面的预期更新频率，帮助蜘蛛合理分配抓取资源；  
- **优先级（priority）**：0.0 到 1.0 的数值，数值越高表示该类型页面在网站中的重要性越高，搜索引擎会据此调整抓取优先级。   

例如首页可设为「每天 + 1.0」，文章可设为「每月 + 0.6」，精准控制搜索引擎对每种页面的关注度。   

### 后台文件管理   

生成 Sitemap 后，后台页面以表格形式展示所有已生成的文件：   

- 文件名和存在状态（已生成 / 未生成）；  
- 文件大小（KB），便于了解 Sitemap 体积；  
- 最后生成时间，确认文件时效性；  
- 「查看」链接，点击直接在新窗口打开 XML 文件内容预览。   

## 使用说明   

### 第一步：安装插件   

将 `sitemap_gen` 文件夹上传至网站 `zb_users/plugin/` 目录，进入 Z-BlogPHP 后台「插件管理」页面，找到「XML Sitemap 生成器」并点击启用。   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-11.png)   

### 第二步：配置参数   

进入后台「插件管理 → Sitemap 生成器 → 设置页面」：   

- **文件名**：设置 Sitemap 文件的基础名称，默认为 `sitemap`，生成的文件为 `sitemap.xml` 等；  
- **分类模式**：选择单文件、按类型拆分或按分类拆分三种模式之一，推荐选择「按类型分文件」以获得最佳 SEO 效果；  
- **发布文章自动生成**：勾选后发布或更新文章/页面时自动重建 Sitemap；  
- **定时自动生成间隔**：设置定时重建的天数间隔，0 表示关闭定时功能；由访客请求触发，无需服务器 Cron；  
- **内容类型设置**：针对首页、分类、标签、文章、页面分别设置是否收录、更新频率和优先级。   

配置完成后点击「保存设置」。   

### 第三步：生成 Sitemap   

点击「立即生成 Sitemap」按钮手动生成。生成完成后，页面下方文件列表会显示所有生成的文件及详细信息。点击文件名旁的「查看」链接可直接预览 XML 内容。   

### 第四步：提交到搜索引擎   

Sitemap 文件生成后，可将其 URL 提交到各大搜索引擎的站长平台：   

- Google Search Console：在「站点地图」页面提交 `https://你的域名/sitemap.xml`；  
- Bing 网站管理员工具：在「站点地图」页面提交相同的 URL；  
- 百度搜索资源平台：在「数据引入 → 链接提交 → Sitemap」中提交。   

搜索引擎将定期抓取您提交的 Sitemap 文件，根据其中的 URL 列表发现和收录网站页面。   

## 注意事项   

- 本插件生成的是 XML Sitemap 文件（符合 sitemaps.org 协议标准），存储在网站根目录，搜索引擎通过该文件了解网站页面结构，并非直接提升排名；  
- Sitemap 文件写入网站根目录，请确保 `zb_users/plugin/sitemap_gen/` 目录（用于缓存状态）和网站根目录（用于写入 XML 文件）具有写入权限；  
- 定时重建依赖访客请求触发，如果网站在设定间隔时间内没有任何访客访问，定时重建不会执行，可结合手动生成按钮确保文件更新；  
- 按分类拆分模式下，文章只按分类文件输出，不再生成独立的文章类型文件，避免重复收录；  
- 如果之前使用其他 Sitemap 插件，建议先卸载旧插件并删除其生成的旧 Sitemap 文件，再启用本插件避免文件冲突。
