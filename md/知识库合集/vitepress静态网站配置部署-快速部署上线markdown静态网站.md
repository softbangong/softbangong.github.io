快速部署上线一个自己的网站，零成本，最主要的是快，而且傻瓜式部署。   

## 演示站点   

https://doc.softbangong.top/doc/   

## 准备工作：   

**1、需要安装Node.js**   

VitePress 是基于 Node.js 的静态站点生成器，其构建过程必须依赖 Node.js 运行时环境   

下载地址：<https://nodejs.org/zh-cn/download>   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-40.png)   

安装方式：下载后双击安装即可，全部默认也行   

**2、php服务**   

将php下载后解压到这个文件夹下，手动创建php文件夹   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-41.png)   

**php文件夹内容展示**   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-42.png)   

现在将vitepress下载到本地就可以写内容了   

md文件夹下可以创建分类文件夹，分类文件夹下放markdown文档也就是写的文章   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-43.png)   

image文件夹下放图片文件，图片也可以使用外链图床比如借用piggo   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-44.png)   

写好文章后，使用构建工具构建，然后推送到github page上，就可以进行访问了，也可以绑定自定义域名   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-45.png)   

## 注意事项：   

1、国内访问github可能慢，但是可以使用cloudflare对域名进行cdn加速，完美避免国内访问问题   

github page部署静态网页+cloudflare cdn加速完美实现个人网站，且没有费用，稳定靠谱一直在线，如果需要绑定自己的域名，则只需要每年的域名费用。
