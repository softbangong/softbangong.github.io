## 批量创建以压缩包名命名的文件夹并解压-批量去除文件及文件夹名空格-获取指定目录下一级文件夹完整路径-并压缩文件夹   

功能简介：   

1、批量创建以压缩包名命名的文件夹并批量解压压缩包   

2、批量去除文件名中的空格（包含文件及子文件及文件夹   

3、获取指定文件夹下的一级文件夹的完整路径   

4、批量压缩文件夹   

wenjianjiamulu.txt 该文件存放需要压缩的文件夹完整路径   

从解压压缩包，到重新压缩全流程，按照视频演示进行   

以上每个单程序可单独使用，具体使用实现过程可以参考演示视频，使用前请先小规模测试后再大范围使用

### 📑 使用场景例子展示   

A文件夹下有很多不同类型的文件，同时有B、C、D....等文件夹，B、C、D....等这些文件夹下边还有子文件夹，子文件夹下也有文件。   

【操作方法】：   

使用程序1，可以将A文件夹下所有压缩包进行解压，解压后的文件放在以压缩包名字创建的文件夹内，解压完成后会删除压缩包。   

使用程序2，可以将A文件夹下包括子文件夹下文件名中的空格。   

使用程序3，可以将A文件夹下所有一级文件夹完整路径写入到wenjianjiamulu.txt文档中。   

使用程序4，可以将wenjianjiamulu.txt里文件夹压缩为压缩包。   

### **▶** winrar程序安装说明，这步必须操作：   

注意：安装路径必须为此处：D:\rar\，**提示：**请提前在D盘创建文件夹：rar   

如果没有D盘，则安装在C盘，然后修改代码部分即可，如下所示：   

将程序 1 中代码中的这部分代码 set WinRAR="D:\rar\rar.exe" 修改为 set WinRAR="C:\rar\rar.exe"    

将程序 4 中代码中的这部分代码 set RAR="D:\rar\rar.exe"  修改为 set RAR="C:\rar\rar.exe"
