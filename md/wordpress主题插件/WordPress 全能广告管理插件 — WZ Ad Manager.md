# WordPress 全能广告管理插件 — WZ Ad Manager   

> 支持图片和 HTML 代码两种广告类型，覆盖文章正文、列表信息流、弹窗、插屏、右下角、滑入、对联、顶部通栏、底部通栏、搜索页、归档页、404 页面等 20 余种投放位置，助您灵活变现网站流量。
   

**版本**：v1.5.6  
**适配**：WordPress 5.0+  
**PHP**：≥ 7.2  
**作者**：softbangong  
**授权**：不限制网站数量，下载安装后永久免费使用   

## 插件简介   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-35.png)   

本插件为 WordPress 网站提供一站式的广告投放管理方案，支持图片广告和 HTML 代码广告两种类型。您可以为每条广告自由选择 20 余个投放位置、指定生效时间范围、限定展示的文章分类，并通过权重或随机模式控制多广告轮播策略。   

插件内置完善的广告展示控制逻辑：支持按权重轮播的 Cookie 机制、移动端独立开关、搜索引擎蜘蛛免展示，以及图片自适应缩放、新窗口打开、nofollow 等 SEO 友好选项。同时提供每日展现量和点击量的实时统计，方便您评估广告效果和调整投放策略。   

后台管理界面采用三标签页布局（广告列表、添加广告、插件设置），支持列表内快速编辑图片地址、跳转链接、权重和时间范围，无需进入编辑页面即可完成日常调整。内置图库功能，可将广告素材上传至插件自有目录统一管理。   

## 功能特性   

### 20 余种广告投放位置   

插件将投放位置按场景分为四组，每条广告可同时勾选多个位置：   

| 分组 | 位置 | 说明 |
| --- | --- | --- |
| 文章内 | 文章顶部、文章中部、文章底部、第 N 段后、H 标签后 | 嵌入文章正文内容区域，可指定段落序号或标题级别 |
| 文章周边 | 面包屑导航下方、评论区、原生推荐 | 围绕文章内容区域的辅助展示位 |
| 页面级 | 弹窗、插屏、右下角、滑入、对联、顶部通栏、底部通栏 | 独立于文章内容的全局展示位，支持倒计时、滚动触发等特殊交互 |
| 页面级 | 弹窗、插屏、右下角、滑入、对联、顶部通栏、底部通栏 | 独立于文章内容的全局展示位，支持倒计时、滚动触发等特殊交互 |
   

每个位置均可在插件设置的「位置总开关」中独立启用或关闭。   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-36.png)   

### 两种广告类型   

- **图片广告**：上传或粘贴图片 URL，支持设置跳转链接。图片自适应容器宽度，支持 object-fit 缩放模式（contain / cover / fill / none / scale-down），可限定最大宽度和固定宽高，支持自定义 alt 文本  
- **代码广告**：粘贴任意 HTML 代码（如 Google AdSense、联盟广告等），插件自动过滤 script 标签、on 事件属性和 javascript: 伪协议，保障网站安全   

### 多广告轮播策略   

当同一位置存在多条符合条件的广告时，支持三种轮播模式：   

- **随机模式**：每次页面加载随机展示一条，最简单公平  
- **权重轮播模式**：按广告权重值从高到低排序，通过 Cookie 记录轮播位置，每次展示下一个广告，一小时后重置，实现按比例曝光  
- **全部展示模式**：将该位置所有符合条件的广告同时输出   

### 广告定时投放   

每条广告可独立设置生效的起止时间。到达开始时间后自动上线展示，超过结束时间后自动停用，无需手动操作。适用于限时促销、节假日活动等场景。   

### 分类定向投放   

可指定广告仅在特定文章分类下展示。未设置分类限制的广告在所有文章中生效，实现精准的广告投放策略。   

### 每日数据统计   

插件通过 AJAX 自动收集每条广告的每日展现量和点击量，在广告列表中实时显示今日数据，方便您快速评估各广告位的效果表现。   

### 搜索引擎蜘蛛过滤   

开启蜘蛛过滤后，插件会识别 Googlebot、Bingbot、Baiduspider、Sogou、360Spider 等主流搜索引擎爬虫的 User-Agent，对其隐藏所有广告内容，避免广告影响 SEO 收录和页面评分。   

### 移动端独立控制   

插件内置移动设备检测，可一键关闭所有广告在手机、平板等设备上的展示，避免移动端广告影响用户体验。检测覆盖 Android、iPhone、iPad、Windows Phone 等主流移动平台。   

### 特殊广告交互   

- **弹窗广告**：页面加载后弹出居中模态窗口，用户可点击关闭按钮或遮罩层关闭  
- **插屏广告**：全屏覆盖式广告，带倒计时器和跳过按钮，倒计时结束后关闭按钮才可点击。关闭倒计时秒数可自定义（1-30 秒）  
- **滑入广告**：用户滚动页面至设定百分比时从页面边缘滑入展示，可自定义触发比例（1-100%）和对齐方式。关闭后本次会话不再出现  
- **右下角广告**：固定在页面右下角，可自定义距右侧边缘的像素距离  
- **对联广告**：页面左右两侧各展示一条对联式广告，随页面滚动悬浮   

### 评论区广告精准插入   

支持在文章评论区顶部、中间或底部插入广告，可设定广告展示次数（如仅在第一条评论后展示）。广告自动跟随评论区的 DOM 结构动态定位。   

### 列表信息流广告   

在文章列表页（首页、分类页、标签页等）中，每隔指定条数插入一条信息流广告，原生融入列表布局。插入间隔数量可在每条广告中独立配置。   

### 内置图库管理   

插件提供独立的图片图库功能，支持上传 JPG、PNG、GIF、WebP 格式图片到插件自有目录。图库中的图片可在添加广告时一键选用，无需通过 WordPress 媒体库。   

### 列表内快速编辑   

广告列表中可直接修改图片 URL、跳转链接、权重值、生效时间范围，修改后即时保存，无需跳转到编辑页面，大幅提升日常管理效率。   

### 中英双语界面   

后台管理界面和前台广告标识均支持中文和英文两种语言，一键切换。所有文案通过统一的文本映射表管理，扩展和维护方便。   

### 广告标识与关闭   

前台展示的每条广告均附带「广告」标识徽章，明确告知用户内容性质。弹窗、插屏、滑入等特殊广告自带独立关闭按钮，其余位置的广告也提供统一的关闭功能，用户可手动关闭不感兴趣的广告内容。   

### 安全代码过滤   

HTML 代码广告在输出前经过三层安全过滤：移除 script 标签及其内容、移除 on 事件属性、将 javascript: 伪协议链接替换为占位符。从源头杜绝 XSS 攻击风险。   

## 使用说明   

### 第一步：安装插件   

将 wz_ad 文件夹上传至网站 wp-content/plugins/ 目录，进入 WordPress 后台「插件」页面，找到「WZ Ad Manager 全能广告管理」并点击启用。启用后插件会自动创建所需的数据表，并在左侧菜单栏添加「广告管理」入口。   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-37.png)   

### 第二步：创建广告   

进入后台「广告管理 → 添加广告」页面：   

- 填写广告名称（必填），选择广告类型（图片广告或代码广告）  
- 图片广告：上传图片或输入图片 URL，可选填点击跳转链接  
- 代码广告：粘贴 HTML 广告代码，插件自动过滤危险标签  
- 在「投放设置」区域勾选一个或多个展示位置。位置按分组排列，支持多选  
- 可选设置：文章分类限制、权重值、生效起止时间、对齐方式  
- 部分位置有专属设置项（如评论区位置/数量、段落序号、插屏倒计时秒数、信息流插入间隔、滑入触发比例、右下角边距等），勾选对应位置后自动展开   

填写完毕后点击「保存广告」提交。   

### 第三步：配置全局设置   

进入后台「广告管理 → 插件设置」页面：   

- 总开关：一键启用或停用所有广告展示  
- 展示模式：选择随机、权重轮播或全部展示  
- 移动端展示：开启或关闭移动设备上的广告  
- 蜘蛛过滤：开启后对搜索引擎爬虫隐藏广告  
- 图片设置：最大宽度、宽高限定、缩放模式、alt 文本  
- 链接设置：新窗口打开、添加 nofollow 属性  
- 位置总开关：独立控制 20 余个投放位置的启停  
- 语言切换：中文 / 英文界面一键切换   

### 第四步：查看数据与调整   

- 在「广告列表」页面查看所有广告及其今日展现量、点击量  
- 直接在列表中修改图片 URL、跳转链接、权重、生效时间  
- 点击「编辑」进入详细编辑页面，点击「启用/禁用」快速切换广告状态  
- 通过「快速改位置」按钮可在弹窗中调整广告的投放位置   

## 注意事项   

- 本插件通过 WordPress 的 the_content 过滤器在文章内容中插入广告，与大多数主题兼容。如遇到广告位置异常，请检查主题是否使用了自定义的内容输出方式  
- 代码广告仅支持安全的 HTML 内容，script 标签、事件属性和 javascript: 伪协议会被自动过滤移除。如需投放 JavaScript 广告代码（如 AdSense），建议通过 WordPress 小工具或主题自定义区域投放  
- 插屏广告和弹窗广告在移动端可能影响用户体验和搜索引擎评分，建议配合「移动端展示」开关和「蜘蛛过滤」功能合理使用  
- 权重轮播依赖 Cookie 机制，如用户浏览器禁用了 Cookie，将降级为按权重排序后展示第一条  
- 分类定向仅在文章详情页生效，列表页、搜索页、404 页等非文章页面不受分类限制  
- 每日统计数据的收集依赖前端 JavaScript，如用户浏览器禁用了 JS 或使用了广告拦截插件，统计数据可能不完整
