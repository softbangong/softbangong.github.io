# WordPress 后台实用工具插件 — More Tools   

> 集成搜索蜘蛛拦截、404 跳转、后台体验增强、快捷菜单等实用功能于一体的 WordPress 后台工具集，模块化卡片式管理，中英文双语界面。
   

**版本**：v1.0.0  
**适配**：WordPress 5.8+  
**PHP**：≥ 7.2  
**作者**：softbangong  
**授权**：不限制网站数量，下载安装后永久免费使用   

## 插件简介   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-24.png)   

More Tools 是一款独立的后台实用工具集插件，将多个 WordPress 管理优化功能整合为一站式配置面板。插件采用模块化卡片布局，每个功能配有独立开关，支持实时展开/折叠子配置区，操作直观流畅。   

插件内置中英文双语界面，支持自动、中文、English 三种语言模式切换，切换即时生效无需刷新页面。同时具备从旧版 AntiBot 插件自动迁移配置的能力，升级用户无需重新设置即可直接使用。   

## 功能特性   

### 访问与跳转   

**搜索蜘蛛拦截**   

检测访问 `/wp-login.php`、`/wp-admin/`、`/xmlrpc.php` 路径的 User-Agent，匹配已知搜索引擎爬虫（Googlebot、Baiduspider、Bingbot、360Spider、Bytespider、YisouSpider、Petalbot、YandexBot、DuckDuckBot、Sogou、Applebot 等 20 余种）后直接返回 403 Forbidden，防止爬虫消耗服务器资源及暴露管理入口。   

**404 跳转**   

将网站 404（未找到）页面自动跳转至指定 URL。支持即时跳转（302）和延迟跳转（通过 meta refresh，0-30 秒可调），适用于旧链接重定向、自定义 404 页面等场景。跳转目标地址完全自定义，可指向任意合法 URL。   

### 后台体验   

**固定侧边栏菜单**   

页面滚动时左侧管理菜单栏保持固定不动，无需回到顶部即可随时操作菜单项。响应式兼容移动端和 PC 端，不影响折叠菜单模式。   

**侧边栏溢出滚动**   

当后台菜单项超出屏幕高度时，侧边栏自动启用垂直滚动。同时优化 hover 子菜单交互：鼠标悬停菜单项时，子菜单以浮动层形式跟随显示在侧边栏右侧，并智能判断屏幕底部空间自动向上或向下展开，确保子菜单始终完整可见。   

**自定义侧边栏宽度**   

可自定义后台左侧菜单栏宽度，范围 120-300 像素（默认 160 像素）。启用后折叠菜单模式下的宽度保持 36 像素不受影响，内容区域自动适配新宽度。   

**圆形头像**   

将后台管理工具条和用户资料页的头像统一显示为圆形，提升视觉整洁度。   

**隐藏仪表盘模块**   

隐藏 WordPress 仪表盘默认模块（欢迎面板、快速草稿、活动、站点健康状态等），提供更干净的仪表盘视图。仅在仪表盘页面生效，不影响其他后台页面。   

**返回顶部/底部按钮**   

在所有后台页面右下角显示固定的返回顶部和前往底部按钮，可根据需要独立启用或关闭这两个按钮。支持自定义右侧距离、底部距离、按钮尺寸、按钮颜色和滚动显示阈值，满足不同使用偏好。按钮在页面滚动超过阈值后渐显，点击后平滑滚动到目标位置。   

**一键清理缓存**   

在顶部管理工具条添加「清理 WordPress 缓存」快捷按钮，点击即刷新 WordPress 对象缓存（Object Cache），无需进入设置页面操作。同时插件设置页也提供独立的缓存清理按钮。   

### 快捷菜单   

**顶部快捷菜单**   

在管理工具条添加「快捷菜单」入口，可自定义子菜单项列表。每个菜单项按「名称|地址」格式一行一个配置，支持完整 URL 和相对路径（如 `/wp-admin/plugins.php`），插件自动补全路径。适合将常用管理页面、外部工具链接等集中收纳，提升操作效率。   

**隐藏菜单关键词**   

根据关键词隐藏后台左侧菜单栏和顶部工具条中的菜单项。关键词按行或竖线（|）分隔，支持多关键词组合匹配。匹配逻辑基于菜单文本内容，点击隐藏区域的菜单项仍可通过直接 URL 访问。   

## 使用说明   

### 第一步：安装插件   

将 `more-tools` 文件夹上传至网站 `/wp-content/plugins/` 目录，进入 WordPress 后台「插件管理」页面，找到「More Tools」并点击启用。   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-25.png)   

### 第二步：配置功能模块   

插件激活后，后台左侧菜单栏会出现「实用工具」菜单项，点击进入插件设置页面。页面按功能分为三大模块卡片：   

- **访问与跳转**：蜘蛛拦截开关、404 跳转开关及跳转地址/延迟配置；  
- **后台体验**：固定菜单、圆形头像、隐藏仪表盘、侧边栏滚动、自定义宽度、返回顶部/底部按钮、缓存清理按钮等独立开关及子配置；  
- **快捷菜单**：顶部快捷菜单开关、菜单项列表、隐藏关键词列表。   

每个功能配有独立 toggle 开关，开关右侧有功能说明文字。部分功能（如 404 跳转、自定义侧边栏宽度、返回顶部/底部按钮）开启后会自动展开对应的子配置区域，关闭时自动折叠。点击页面底部「保存设置」按钮统一保存所有配置。   

### 第三步：语言切换   

设置页面顶部工具条提供语言切换下拉菜单，支持自动（跟随站点语言）、中文、English 三种模式。切换后页面文本即时更新，不影响已保存的配置。   

### AntiBot 用户升级说明   

如果您之前使用过 AntiBot 插件，More Tools 在首次激活时会自动读取并迁移 AntiBot 的配置数据，无需手动重新设置。迁移仅执行一次，后续配置互不影响。   

## 注意事项   

- 蜘蛛拦截通过 User-Agent 字符串匹配判断爬虫身份，依赖爬虫如实发送 UA，无法防御恶意伪造 UA 的请求；  
- 404 跳转功能仅在 WordPress 正常识别为 404 页面时触发，如主题自定义 404 处理逻辑可能与插件冲突；  
- 固定侧边栏和侧边栏滚动功能互斥，同时启用时滚动模式优先级更高；  
- 自定义侧边栏宽度需合理设置，过小可能导致菜单文字被截断；  
- 隐藏菜单关键词仅在后台管理页面生效，不影响前台菜单显示；  
- 清理缓存功能调用 `wp_cache_flush()`，依赖站点使用的对象缓存实现机制。
