# WordPress 弹窗广告插件 — Popup Ads   

> 为 WordPress 网站提供 PC 端与移动端独立配置的弹窗广告位，支持 HTML 代码和纯文本两种内容模式，内置 Cookie 关闭计时器避免反复打扰访客，支持自定义 CSS 与中英双语后台管理。
   

**版本**：v2.1.4  
**适配**：WordPress 5.0+  
**PHP**：≥ 7.2  
**作者**：softbangong  
**授权**：不限制网站数量，下载安装后永久免费使用   

## 插件简介   

![](https://www.softbangong.com/wp-content/uploads/2026/07/1334c707-c71c-4b26-ba8a-a6ed24d10d15.png)   

本插件用于在 WordPress 网站前台展示弹窗广告或公告内容。PC 端与移动端各提供三个弹窗位置（中间弹窗、左下角弹窗、右下角弹窗），六个位置互不影响，可分别配置内容、标题、尺寸和启用状态。   

插件内置两种内容输入模式：HTML 模式适合嵌入广告代码或图文内容，系统自动过滤 script 标签和事件属性保障安全；文本模式将所有输入进行转义处理，适合展示纯文本公告。访客关闭弹窗后，插件通过 Cookie 记录并在设定时长内不再重复显示，避免过度干扰用户体验。   

后台管理界面支持中英文双语切换，提供全局开关、移动端显示控制、自定义 CSS、水印文字等集中化设置，每个弹窗位置还可独立控制水印显示。   

## 功能特性   

### PC 端与移动端独立弹窗位   

插件为 PC 端和移动端分别提供三个弹窗位置，共六个独立配置单元：   

| 端 | 位置 | 说明 |
| --- | --- | --- |
| PC 端 | 中间弹窗 | 页面居中弹出，适合重要公告或大型广告 |
| PC 端 | 左下角弹窗 | 从左下角滑入，适合轻量推广信息 |
| PC 端 | 右下角弹窗 | 从右下角滑入，适合轻量推广信息 |
| 移动端 | 中间弹窗 | 移动端居中弹出，自适应屏幕宽度 |
| 移动端 | 左下角弹窗 | 移动端左下角滑入 |
| 移动端 | 左下角弹窗 | 移动端左下角滑入 |
   

每个弹窗位置均可独立设置内容、标题、宽度、高度和水印显示，互不干扰。   

### HTML 与文本双模式内容   

每个弹窗支持两种内容模式，可在后台随时切换：   

— **HTML 模式**：适合嵌入广告代码、图片、iframe 等 HTML 内容。系统自动过滤 script 标签、onclick 等事件属性和 javascript: 伪协议链接，仅保留安全的 HTML 标签和属性，确保网站不被恶意代码注入；   

— **文本模式**：适合展示纯文本公告。输入内容会自动转义 HTML 特殊字符并保留换行，以带标题栏的公告卡片样式呈现，视觉效果清晰规范。   

### Cookie 关闭计时器   

访客点击弹窗关闭按钮后，插件写入浏览器 Cookie，在设定的秒数内该弹窗不再显示：   

— 关闭计时时长可在后台全局配置，范围 1 至 86400 秒（24 小时）；  
— 每个弹窗位使用独立的 Cookie 名称，关闭某个位置的弹窗不影响其他位置；  
— 计时到期后弹窗自动恢复显示，无需访客手动操作。   

### 动画展示效果   

弹窗出现时带有平滑动画，提升视觉体验而不显突兀：   

— 左下角和右下角弹窗从屏幕底部向上滑入，动画时长 800 毫秒；  
— 中间弹窗从顶部向下滑入至屏幕中央，动画时长 800 毫秒；  
— 关闭弹窗时带 400 毫秒淡出效果。   

### 自定义 CSS   

后台提供自定义 CSS 文本域，输入样式代码后自动注入前台页面：   

— 建议使用 `.tcad-` 选择器限定作用域，避免影响网站其他元素；  
— 支持实时预览，保存设置后立即生效；  
— 系统自动过滤可能引入安全风险的 style 标签和 script 相关内容。   

### 中英双语后台   

管理界面支持中文和英文两种语言，后台顶部下拉框一键切换：   

— 所有界面文案、开关状态提示、占位符说明均支持双语；  
— 语言偏好保存在插件配置中，切换后全局生效。   

### 全局控制与卸载清理   

— 顶部总开关可一键启用或禁用全部弹窗，方便临时关闭所有广告展示；  
— 移动端独立开关控制是否在手机等移动设备上显示弹窗；  
— 卸载时清理配置选项：开启后，删除插件时将自动清除所有数据库配置记录，不留残留数据。   

### 水印文字   

— 全局设置广告提示文字（默认为「广告」），显示在弹窗关闭按钮旁；  
— 每个弹窗位置可独立控制是否显示水印文字；  
— HTML 模式和文本模式均支持水印显示，位置自适应弹窗布局。   

### 安全性设计   

— HTML 模式通过白名单机制过滤标签和属性，仅允许安全的 HTML 元素通过；  
— 自动移除 script 标签、on* 事件属性、javascript: 伪协议；  
— 文本模式对所有输入进行 HTML 实体转义；  
— 管理页面使用 WordPress Nonce 机制防止 CSRF 攻击；  
— 所有用户输入经过 WordPress 内置消毒函数处理。   

### 响应式适配   

— 弹窗在移动端自动调整最大宽度，避免撑破屏幕；  
— 中间弹窗在小屏设备上限制为 90vw；  
— 文本模式公告卡片在小屏下自动缩小字体和间距。   

## 使用说明   

### 第一步：安装插件   

将 `tcad_tanchuang` 文件夹上传至网站 `wp-content/plugins/` 目录，进入 WordPress 后台「插件」页面，找到「弹窗广告位」并点击启用。   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-30.png)   

### 第二步：配置全局设置   

进入后台「设置 → 弹窗广告位」页面：   

— 页面顶部总开关默认开启，可一键关闭所有弹窗；  
— 选择后台界面语言（中文 / English）；  
— 设置移动端是否显示弹窗；  
— 设置关闭后隐藏时长（秒），默认 60 秒；  
— 填写广告提示文字（水印），默认为「广告」；  
— 如需自定义弹窗样式，在「自定义 CSS」文本域中输入 CSS 代码。   

### 第三步：配置弹窗内容   

在「PC 端弹窗广告」和「移动端弹窗广告」两个卡片中分别配置：   

— 为每个弹窗位选择内容模式（HTML 或文本）；  
— 填写弹窗标题（文本模式下显示在公告栏顶部）；  
— 设置弹窗宽度和高度（支持 px、em、rem、%、vw、vh 单位）；  
— 选择是否显示水印文字；  
— 在内容输入框中填写广告代码或文本内容；  
— 开启弹窗的启用开关。   

### 第四步：保存并验证   

— 点击页面底部「保存设置」按钮；  
— 访问网站前台，确认弹窗是否按预期出现在对应位置；  
— 点击关闭按钮测试 Cookie 机制，在设定时长内刷新页面确认弹窗不再出现；  
— 在移动设备上验证移动端弹窗的显示效果。   

## 注意事项   

— 本插件展示的是弹窗层（CSS fixed 定位），并非浏览器原生弹窗，不会被浏览器弹窗拦截器阻止；  
— HTML 模式会自动过滤 script 标签和事件属性，如需嵌入完整 JavaScript 代码请使用其他专业方案；  
— 弹窗尺寸单位支持 px、em、rem、%、vw、vh，留空则使用 CSS 默认值自适应；  
— 移动端弹窗位仅在移动设备上生效（通过 WordPress 内置的 wp_is_mobile() 函数判断），PC 端弹窗位同理仅在桌面设备上显示；  
— 关闭按钮写入的 Cookie 路径为网站根路径（`path=/`），确保全站范围内生效；  
— 自定义 CSS 输入框中的代码会直接输出到前台页面，请确保语法正确以免影响页面样式。
