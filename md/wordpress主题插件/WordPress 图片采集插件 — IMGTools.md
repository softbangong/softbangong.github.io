# WordPress 图片采集插件 — IMGTools   

> 将 WordPress 文章内容中的站外图片一键下载到本地服务器，支持 JPG、JPEG、PNG、GIF、BMP、WebP 等常见图片格式。提供自动 / 手动双采集模式、全局批量扫描、图片水印、代理服务器等完整功能，帮助站长高效管理转载文章中的外部图片资源。
   

**版本**：v1.0.0  
**适配**：WordPress 5.8+  
**PHP**：>= 7.2  
**作者**：softbangong  
**授权**：不限制网站数量，下载安装后永久免费使用   

## 插件简介   

![](https://www.softbangong.com/wp-content/uploads/2026/07/0a2b5d65-2e4b-48be-a184-30b4095e91ad.png)   

本插件用于将 WordPress 文章内容中引用的外部图片自动下载到本地服务器，并替换文章中的图片链接为本地 URL。适用于经常转载文章、需要将外部图片本地化的 WordPress 站长。   

插件在文章编辑器中提供「保存站外图片」按钮，支持一键扫描当前文章全部外部图片并批量下载；同时支持自动采集模式，文章保存时后台自动下载外部图片而无需手动操作。对于已发布的大量历史文章，可通过全局扫描功能批量检测并采集其中的外部图片。   

## 功能特性   

### 双模式采集策略   

— **自动采集模式**：文章发布或更新保存时，插件自动扫描内容中的站外图片并下载到本地，无需手动操作。同时内置每小时定时任务，自动处理自动采集标记的文章中尚未成功下载的图片；  
— **手动采集模式**：在文章编辑器中点击「保存站外图片」按钮，手动触发扫描和下载，逐张确认采集结果，适合对图片质量要求较高的场景；  
— 两种模式可随时在插件设置页面切换。   

### 图片规则配置   

插件支持灵活定义下载后图片的处理规则，每种规则均有独立配置项：   

— **尺寸规则**：支持保留原尺寸、最大宽度 1080px、最大宽度 720px 或自定义最大宽度，超出限制的图片自动等比缩放；  
— **文件名规则**：支持系统自动命名、保留原始文件名或自定义命名规则（支持 `%filename%`、`%date%`、`%year%`、`%month%`、`%day%`、`%random%` 等变量组合）；  
— **标题及 ALT 规则**：支持保留原始 title/alt 属性或使用自定义模板（支持 `%filename%` 和 `%postname%` 变量），末尾自动追加图片序号；  
— **对齐方式**：支持无、左对齐、居中、右对齐四种对齐方式；  
— **删除图片外链**：可自动移除包裹图片的 A 标签链接，只保留图片本身。   

### 过滤规则系统   

插件内置多维度过滤规则，精准控制哪些外部图片需要下载：   

— **排除指定顺序图片**：按图片在文章中出现的序号排除下载，支持逗号分隔多个序号，使用 “z” 代表最后一幅；  
— **最小宽度过滤**：仅下载宽度大于指定像素的图片，自动跳过尺寸过小的图标或装饰图；  
— **域名排除**：排除指定域名的图片不下载，支持每行一个域名批量配置，避免将 CDN 图片或图库外链误采到本地；  
— **格式过滤**：勾选的图片格式将被排除下载，支持 JPG、JPEG、PNG、GIF、BMP、WebP 六种格式独立勾选；  
— **自动去重**：相同 URL 的外部图片仅下载一次，多次引用时自动复用本地图片链接。   

### 代理服务器支持   

— 支持手动配置代理服务器（IP、端口、用户名、密码），解决部分海外服务器网络不通或下载速度慢的问题；  
— 手动采集时可灵活选择使用默认代理、手动配置的代理或不使用代理；  
— 适用于采集海外网站图片或服务器位于境外但需要采集国内图片的场景。   

### 图片水印功能   

支持为下载后的图片自动添加水印保护，需要服务器安装 PHP Imagick 扩展：   

— **图片水印**：支持上传自定义水印图片，可设置透明度（0-100%）和水印位置（右下方、左下方、右上方、左上方、正中心、自定义位置），自定义位置支持百分比偏移；  
— **文字水印**：支持自定义水印文字、字体大小、字体颜色和透明度，内置思源黑体中文字体，水印位置同样支持六种定位方式；  
— **应用范围**：支持仅对新图片添加水印或对所有图片（含已上传图片）添加水印，选择「所有图片」时通过每小时定时任务逐批处理旧图片（每次最多 10 张）；  
— **尺寸门槛**：可设置水印生效的最小宽度和最小高度，低于此尺寸的图片自动跳过水印处理；  
— **原图备份**：添加水印前自动将原图备份至 `/uploads/#original/` 目录，支持一键恢复原图或删除备份以释放空间。   

### 全局扫描批量采集   

对已发布的历史文章进行全站外部图片扫描和批量下载：   

— **扫描类型**：支持按文章、页面等公开文章类型筛选；  
— **文章状态**：支持按已发布、草稿等状态筛选；  
— **分类筛选**：支持按分类目录筛选，自动包含子分类下的文章；  
— **ID 范围**：支持指定起始 ID 和结束 ID 区间；  
— **日期范围**：支持按文章发布日期的起止区间筛选；  
— **排序方式**：支持最新优先或最早优先两种排序；  
— **分批扫描**：采用分批扫描机制，每批处理 10 篇文章，支持断点续扫，避免一次性扫描大量文章导致服务器负载过高；  
— 扫描结果可逐张查看并下载，下载完成后自动替换文章中的图片链接。   

### 编辑器深度集成   

— **经典编辑器**：在编辑器工具栏提供「保存站外图片」按钮，点击弹出采集窗口，实时显示扫描到的外部图片列表和下载进度；  
— **古腾堡区块编辑器**：同样提供采集按钮，完全兼容区块编辑器环境；  
— **剪贴板粘贴上传**：支持从剪贴板直接粘贴图片到编辑器，自动上传到 WordPress 媒体库；  
— **文件上传**：支持通过采集窗口直接上传本地图片文件。   

### 中英文双语界面   

— 支持中文、英文和自动（跟随 WordPress 站点语言）三种界面语言切换；  
— 通过 gettext 过滤器 + PHP 翻译数组实现内部翻译，不依赖 .mo/.po 文件；  
— 所有前端提示信息和管理后台设置项均完整覆盖双语翻译。   

## 使用说明   

### 第一步：安装插件   

将 `imgtools` 文件夹上传至网站 `wp-content/plugins/` 目录，进入 WordPress 后台「插件」页面，找到「IMGTools」并点击启用。   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-23.png)   

### 第二步：配置采集参数   

进入后台「设置 → IMGTools」配置页面：   

— **采集设置**卡：选择采集模式（自动 / 手动），决定是否将第一张图片设为特色图片、是否删除图片外链；  
— **图片规则**卡：配置尺寸规则、文件名规则、标题及 ALT 规则和对齐方式；  
— **过滤规则**卡：按需设置排除序号、最小宽度、排除域名和格式过滤等过滤条件；  
— **代理设置**卡：如需使用代理下载图片，填入代理服务器信息并启用；  
— **水印设置**卡：选择水印类型（图片 / 文字），上传水印图片或填写水印文字，设置位置、透明度等参数。水印预览功能可即时查看效果。   

### 第三步：采集文章图片   

**手动模式**：编辑文章时，点击编辑器工具栏的「保存站外图片」按钮，在弹出的采集窗口中查看扫描结果，确认后点击「全部下载」完成采集。也可以逐张点击单独下载。   

**自动模式**：文章发布或更新保存时，插件自动在后台下载外部图片并替换链接，无需额外操作。自动模式下也可手动触发采集。   

### 第四步：全局扫描历史文章   

进入后台「设置 → IMGTools → 全局扫描」：   

— 按需设置扫描类型、文章状态、分类、ID 范围、日期范围等筛选条件；  
— 点击「开始扫描」，插件分批扫描符合条件的文章并列出所有外部图片；  
— 扫描完成后可逐张下载或批量全部下载，下载成功即自动替换文章中的对应图片链接。   

### 第五步：水印维护   

在「水印设置」卡配置好水印参数并保存后，新下载的图片会自动添加水印。如需对历史图片批量添加水印，将「应用范围」设置为「所有图片」，插件会通过定时任务每小时自动处理最多 10 张未添加水印的旧图片。   

在「维护工具」卡中：   

— 点击「恢复水印备份」可将所有已添加水印的图片恢复为原始版本；  
— 点击「删除水印备份」可彻底删除备份目录以释放服务器存储空间。   

## 注意事项   

— 图片水印功能需要服务器 PHP 安装并启用 Imagick 扩展，未安装则水印设置不生效（但不影响其他采集功能）；  
— 自动采集模式下，若文章保存时因网络问题导致图片下载失败，原外部 URL 会保留，建议定期使用全局扫描检查并补采；  
— 使用代理服务器需要自行搭建或获取可用代理，插件不提供默认代理服务；  
— 全局扫描可能消耗较多服务器资源，建议按分类、ID 区间或日期范围分批进行，不要一次性全站扫描；  
— 水印仅对 JPG、JPEG、PNG 格式图片生效，GIF 动图自动跳过；  
— 尺寸缩放仅对 JPG、JPEG、PNG 格式生效，WebP、GIF、BMP 等格式保持原尺寸；  
— 原图水印备份存放于 `/wp-content/uploads/#original/` 目录，请勿手动删除以免影响恢复功能。
