# WordPress 登录地址重命名插件 — Rename Login   

> 将 WordPress 默认的 wp-admin 和 wp-login.php 登录入口重命名为自定义 URL，隐藏后台登录地址，有效防御暴力破解和恶意扫描。支持登录页自定义美化、未登录访问自动重定向、中英双语界面，兼容多站点网络。
   

**版本**：v1.0.0  
**适配**：WordPress 5.8+  
**PHP**：>= 7.2  
**作者**：softbangong  
**授权**：不限制网站数量，下载安装后永久免费使用   

## 插件简介   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-29.png)   

本插件用于隐藏 WordPress 默认的后台登录入口。默认情况下，任何访客都可以通过 `/wp-admin` 或 `/wp-login.php` 直接访问登录页面，这让网站暴露在暴力破解攻击和恶意扫描的风险之下。   

插件通过 URL 拦截和重写机制，将默认登录入口替换为您自定义的地址（如 `/my-login`）。激活后，原有的 `wp-admin` 和 `wp-login.php` 将无法直接访问，未登录用户访问后台时会自动跳转到自定义登录页或您指定的页面。   

插件同时提供了一个完全独立的自定义登录页模板，支持品牌色、渐变背景、Logo 图片、卡片尺寸等可视化定制，且不依赖任何 WordPress 主题样式，确保登录页外观始终统一可控。   

## 功能特性   

### 自定义登录地址   

在 WordPress 后台「设置 → Rename Login」页面中，设置您专属的登录地址 slug（如 `login`、`admin-panel`、`secret-door`），插件自动完成以下工作：   

- 注册自定义 Rewrite 规则，使 WordPress 识别并响应新的登录 URL；  
- 拦截所有对 `wp-login.php` 和 `wp-admin`（未登录时）的直接访问，将其重定向到首页或指定页面；  
- 过滤站点所有 URL 输出（`site_url`、`wp_redirect`、欢迎邮件等），将其中出现的 `wp-login.php` 自动替换为新地址；  
- 登录地址 slug 变更时，自动刷新 Rewrite 规则，无需手动更新固定链接。   

设置页面顶部实时显示当前有效的完整登录地址，方便确认和收藏。   

### 未登录访问自动重定向   

当未登录用户尝试访问 WordPress 后台（`/wp-admin/`）时，插件自动将其重定向。您可以选择两种处理方式：   

- **默认行为**：跳转到自定义登录页面，并附带 `redirect_to` 参数，登录成功后自动回到目标页面；  
- **自定义重定向**：在「重定向地址」字段填写一个路径（如 `404`），未登录用户访问后台时将跳转到该页面，完全不暴露登录入口的存在。   

### 登录页自定义美化   

启用「登录页美化」开关后，插件使用独立的自定义模板渲染登录页面，完全脱离 WordPress 默认的 `wp-login.php` 样式。可配置以下外观选项：   

- **主色调**：控制登录按钮、输入框聚焦边框、勾选框等元素的主题色，默认为蓝色（`#2563eb`）；  
- **背景渐变**：登录页背景支持双色渐变（起始色 + 结束色），可搭配网站品牌色系；  
- **自定义 Logo**：上传或填写 Logo 图片 URL，替换默认的站点名称文字；Logo 支持设置固定宽度和高度，留空则自适应；  
- **卡片尺寸**：登录表单白色卡片的宽度、最小高度和内边距均可自由调整，适配不同设计需求；  
- **响应式适配**：模板内置移动端断点样式，在小屏幕设备上自动缩小内边距和卡片圆角。   

自定义模板还内置了找回密码和重置密码的完整流程，均在美化后的页面中完成，不回退到默认 `wp-login.php` 界面。   

### 内置中英双语   

插件内置了完整的 PHP 翻译数组，无需 `.mo` / `.po` 翻译文件：   

- 支持「自动」「中文」「English」三种语言模式；  
- 自动模式下根据 WordPress 站点语言自动匹配；  
- 后台设置页面顶部提供语言切换下拉框，即时生效；  
- 所有前端文本（登录页标签、提示信息、错误消息）均根据当前语言设置动态输出。   

### 多站点网络兼容   

插件完整支持 WordPress 多站点网络：   

- 网络管理员可在「网络设置」中配置全站默认登录地址 slug；  
- 各子站点可在各自的「设置 → Rename Login」中独立覆盖；  
- 卸载时自动清理所有子站点的插件选项数据，不留残留。   

### 404 状态码自动修正   

WordPress 在无法匹配到真实页面时会将请求标记为 404。插件通过多层防护机制确保自定义登录地址始终返回 200 状态码：   

- `parse_request` 阶段提前识别登录请求并清除 404 标记；  
- `status_header` 过滤器拦截后端即将发出的 404 状态头并修正为 200；  
- 模板模式下直接设置正确的 HTTP 缓存头（`no-store, no-cache, must-revalidate`）。   

### 安全机制   

- 插件登录地址 slug 自动过滤 WordPress 保留路径（如 `wp-admin`、`wp-login` 及所有公共查询变量），防止冲突；  
- 登录页模板添加 `noindex,nofollow,noarchive` 元标签，避免搜索引擎收录登录页面；  
- 阻止 WordPress 对 `/wp-signup` 和 `/wp-activate` 的未授权访问（非多站点环境）。   

## 使用说明   

### 第一步：安装插件   

将 `rename_login` 文件夹上传至网站 `wp-content/plugins/` 目录，进入 WordPress 后台「插件」页面，找到「Rename Login | 登录地址重命名」并点击启用。   

![](https://www.softbangong.com/wp-content/uploads/2026/07/image-28.png)   

### 第二步：配置登录地址   

进入后台「设置 → Rename Login」页面：   

- 在「登录地址」输入框中填写您想要的自定义 slug（如 `my-login`），页面顶部会实时显示变更后的完整 URL；  
- 保存设置后，请务必收藏或牢记新的登录地址，因为原有的 `wp-admin` 和 `wp-login.php` 将无法直接访问；  
- 如果新地址访问出现 404，点击页面上的「打开固定链接设置」按钮，在固定链接页面点击一次「保存更改」即可。   

### 第三步：配置重定向地址（可选）   

- 在「重定向地址」输入框中填写一个站点路径（如 `404`），未登录用户访问后台时将跳转到该页面；  
- 留空则跳转到新的自定义登录页面。   

### 第四步：启用登录页美化（可选）   

- 打开「登录页美化」模块的开关；  
- 按需调整主色调、背景渐变色、自定义 Logo 等外观选项；  
- 保存后访问新的登录地址即可看到美化效果。   

### 后续维护   

- 您可以随时回到设置页面修改登录地址 slug，插件会自动刷新 Rewrite 规则；  
- 如果忘记自定义登录地址，可通过 SFTP/FTP 或主机文件管理器删除插件目录 `/wp-content/plugins/rename_login`，网站将恢复默认登录入口；  
- 停用插件后所有自定义设置会被保留，重新激活时无需重新配置。   

## 注意事项   

- 插件通过 URL 拦截实现登录地址隐藏，不会修改任何 WordPress 核心文件；  
- 设置新登录地址后，请务必收藏或牢记新的 URL；一旦忘记，只能通过服务器文件管理删除插件来恢复默认入口；  
- 自定义登录地址不能使用 `wp-login`、`wp-admin` 等 WordPress 保留词汇，插件会自动过滤并回退为 `login`；  
- 与 BuddyPress 和 Buddyboss 不兼容，这两款插件有独立的 `wp-admin` 重定向机制；  
- 登录页美化功能使用独立模板渲染，与主题的登录页定制代码互不冲突。
