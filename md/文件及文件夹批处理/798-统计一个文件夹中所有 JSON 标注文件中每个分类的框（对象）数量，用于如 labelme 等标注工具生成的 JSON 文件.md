作用是统计一个文件夹中所有 JSON 标注文件中每个分类的框（对象）数量，尤其是用于如 labelme 等标注工具生成的 JSON 文件。   

![](https://www.softbangong.com/wp-content/uploads/2026/04/20250416140805174478368595186.png)   

读取用户输入的文件夹路径下所有json文件。   

统计每个标签（label）对应的数量。   

['shapes']：是 labelme 的标注数据格式，其中包含所有框及其 label。   

输入路径  
E:\json文件夹   

分类结果 {'名称1': 12, ''名称2: 8, '名称3': 5 .........}  
总的结果 25   

### 使用环境：   

win7及以上64位操作系统
