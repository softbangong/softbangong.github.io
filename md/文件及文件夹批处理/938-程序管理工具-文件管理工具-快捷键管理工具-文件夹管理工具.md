## 注意事项   

**不要删除数据文件夹**：`dawn_launcher_data` 文件夹保存了你的所有配置和快捷方式，删除后数据会丢失   

**路径有效性**：添加的快捷方式要确保路径是有效的，如果原文件被移动或删除，快捷方式会打不开   

**管理员权限**：某些系统工具（如注册表编辑器）需要管理员权限才能运行，右键选择”以管理员身份运行”   

**符号链接权限**：如果使用软链接模式，需要管理员权限或开启Windows开发者模式   

**快捷键冲突**：默认快捷键是Ctrl+Space，如果和其他软件冲突，可以在设置里改成别的组合键   

**网址格式**：添加网址时，要包含完整的协议头（[http://或https://），例如`https://www.baidu.com`](http://xn--https-wm6j//%EF%BC%89%EF%BC%8C%E4%BE%8B%E5%A6%82%60https://www.baidu.com%60)   

**批量导入数量**：一次性导入太多文件（几百个）可能会稍慢，建议分批导入   

**定期备份**：建议定期备份`dawn_launcher_data`文件夹，防止误删或系统故障导致数据丢失

## 常见问题   

**Q: Dawn Launcher 是什么工具？**  
A: Dawn Launcher 是一款免费的桌面程序管理快速启动工具。它可以帮助你将所有软件、文件夹和网址集中管理，通过网格或列表视图快速启动，支持分类管理（拖拽排序）、软链接、批量导入等功能。   

**Q: Dawn Launcher 支持什么系统？**  
A: 支持 Windows 7/8/10/11 系统，兼容 2K/4K 高DPI分辨率。只支持Windows 64位操作系统。   

**Q: Dawn Launcher 的软链接功能是什么？**  
A: 开启软链接模式后，添加文件/文件夹时会创建符号链接而非直接引用路径。这样可以集中管理文件引用，支持一键在路径模式和链接模式之间批量转换已有项目。软链接模式默认开启。   

**Q: 如何快速添加程序到 Dawn Launcher？**  
A: 支持多种方式：点击「＋ 添加」按钮手动添加、Ctrl+V 粘贴文件/文件夹/网址、点击「导入」批量选择文件和文件夹、从资源管理器拖拽文件。   

**Q: Dawn Launcher 的快捷键是什么？**  
A: 默认全局快捷键为 Ctrl+Space，可快速唤出/隐藏窗口。Ctrl+V 可粘贴剪贴板内容。快捷键可在设置中自定义。   

**Q: 批量导入大量文件会卡顿吗？**  
A: 不会。   

**Q: 配置数据存在哪里？**  
A: 配置数据存储在程序所在目录的 dawn_launcher_data/ 文件夹下，包括 config.json（设置）、data.json（项目数据）、links/（软链接）、dawn_launcher.log（日志）。打包为 exe 后会自动跟随 exe 目录。   

**Q: Dawn Launcher 支持拖拽排序和双击启动吗？**  
A: 支持。网格和列表视图均支持拖拽重排项目顺序，数据自动保存。双击项目即可启动，单击选中，有效避免误操作。   

**Q: 默认系统工具有哪些？**   

![](https://www.softbangong.com/wp-content/uploads/2026/05/image-11.png)   

A: 首次运行自动注入 36 个 Windows 常用工具，**涵盖系统管理**（注册表/组策略/安全策略/计算机管理）、**设备管理**（设备管理器/磁盘管理）、**服务管理**（服务/任务计划/事件查看器/性能监视器）、**网络管理**（网络连接/防火墙/IE属性）、**控制面板**（系统属性/添加删除程序/桌面图标设置）、**系统工具**（命令提示符/PowerShell/MSConfig/DxDiag/截图/屏幕键盘/磁盘清理/资源监视器/系统信息）、**其他**（记事本/计算器/画图/系统还原/Windows功能/资源管理器）等。兼容 Windows 7 及以上版本。   

**Q: 为什么有些程序图标显示不正常？**   

A: 图标是从Windows系统自动获取的。如果图标显示异常，可能是：   
1. 该文件本身没有图标（如.txt、.json等）
2. PIL库未安装（运行`pip install Pillow`安装）
3. 程序会自动生成彩色图标作为替代，不影响使用
   

**Q: 不小心删了快捷方式能恢复吗？**   

A: 只要`dawn_launcher_data`文件夹还在，数据就不会丢。如果误删了：   
1. 打开`dawn_launcher_data\data.json`（用记事本或代码编辑器）
2. 找到”items”数组，里面保存了所有快捷方式
3. 如果文件被误改，可以用备份恢复
   

**Q: 换个电脑怎么迁移数据？**   

A: 很简单：   
1. 在旧电脑上，把整个`dawn_launcher_data`文件夹复制到U盘
2. 在新电脑上，把程序文件和`dawn_launcher_data`文件夹放在同一个相对位置
3. 运行程序，所有快捷方式都还在
