用来快速管理和本地文件/文件夹。  
你可以为每个项目创建一组「快捷按钮」，每个按钮可以对应一个 **文件 / 文件夹 / 网页 URL**   

**支持：**   
- **一键打开** 指定的文件/文件夹/网址
- **拖拽文件/文件夹/URL 到按钮** 即可完成绑定
- **右键按钮** 进行重命名、改颜色、删除该行等操作
- **多项目切换**，每个项目使用独立按钮配置
- **本地搜索** 功能，在项目目录和自定义路径中快速查找文件/文件夹
   

**非常适合用来整理：**项目文档、素材、脚本、常用工具、教程链接等。   

### 功能说明   

### 1. 项目管理标签页   

打开程序后默认进入 **“项目管理”** 标签页，主要区域包括：   
- **顶部项目区域**
    - **新建项目**：创建一个新的项目标签（会在 `projects` 目录下建立同名文件夹）。
    - **添加自定义模块**：为当前项目新增一行按钮（每行 2 个按钮）。
    - **一键恢复默认**：
        - 将当前项目的自定义按钮数量重置为 **50 个**（25 行×2 列）。
        - 清空当前项目所有按钮的路径、名称与颜色。
    - **选择项目下拉框**：选择当前正在编辑/使用的项目。
    - **项目标签栏**：以 Tab 方式展示所有项目，可右键进行「重命名 / 删除」。
- **按钮区域（主体）**
    - 默认每个项目有 **50 个按钮**（25 行 × 2 列）。
    - 每个按钮都可以绑定一个：文件 / 文件夹 / URL。
    - 支持操作：
        - **左键单击**：
            - 若尚未绑定路径：弹出对话框选择文件/文件夹或输入 URL。
            - 若已绑定路径：直接用系统默认程序打开文件/文件夹/网址。
        - **右键按钮**（自定义菜单）：
            - **重新指定**：重新选择该按钮的文件/文件夹/URL。
            - **重命名**：自定义按钮显示名称。
            - **设置颜色**：为按钮设置背景颜色（不同项目、不同按钮可用不同颜色做分组标记）。
            - **删除此行**：删除当前按钮所在的整行（即两个按钮一起删）。
                - 程序保证每个项目最少保留 **50 个按钮**。
            - **恢复默认**：只重置当前按钮（路径+名称+颜色清空）。
        - **拖拽功能**：
            - 直接把文件 / 文件夹 / 浏览器地址栏中的 URL 拖到某个按钮上，即可快速绑定。
            - 拖动按钮可以换位置：按住按钮左键拖到另一个按钮上可交换两者位置。
   

### 2. 本地搜索标签页   

点击上方的 **“本地搜索”** 标签，可以对本地文件进行快速查找。   
- **搜索输入与模式**
    - 文本框：输入文件名、文件夹名或扩展名关键字。
    - 搜索模式：
        - **模糊搜索**：名称中包含关键字即可匹配。
        - **精准搜索**：
            - 若输入包含 `.`，则按完整文件名匹配（例如 `main.py`）。
            - 否则匹配不带扩展名的文件名（例如输入 `main` 会匹配 `main.py`、`main.txt` 中的 `main` 部分）。
        - **扩展名搜索**：按后缀查找（例如输入 `pdf` 或 `.pdf`）。
- **搜索范围选项**
    - **搜索所有项目下的文件及文件夹**：会遍历 `projects` 目录下的所有子项目。
    - **搜索自定义文件夹下的文件或文件夹**：在下方维护一个自定义搜索路径列表。
- **搜索路径列表**
    - **添加搜索路径**：选择某个文件夹作为额外的搜索目录。
    - **清除所有搜索路径**：一键清空列表。
    - 右键某条路径可「删除此路径」。
- **搜索结果表格**
    - 列：**名称 / 路径 / 类型（文件/文件夹）**
    - 支持操作：
        - **双击行**：直接打开文件或文件夹。
        - **右键菜单**：
            - 打开文件/文件夹
            - 复制路径
            - 复制到…（调用系统文件复制）
            - 移动到…（调用系统文件移动）
   

### 配置文件与备份机制   
- 所有配置保存在 **`config.json`** 中。
- 每次保存配置前，程序会自动将旧配置备份为 **`config.json.bak`**，用于防止意外损坏。
   

如果 `config.json` 被删除或损坏，可以将**`config.json.bak`** 文件的.bak删除，然后重新打开程序即可。

### 使用示例一：管理某软件项目的全部资料   

**需求场景**：  
你有一个软件项目「订单管理系统」，其相关资料分散在不同位置：需求文档、UI 设计稿、接口文档、测试用例、打包输出目录、线上文档链接等，希望统一集中在一个界面一键打开。   

### 步骤   
1. 在 **“项目管理”** 标签页中点击 **“新建项目”**，输入项目名称：`订单管理系统`。
2. 在按钮区域中，选择第一个按钮：
    - 直接点击按钮 → 弹出「输入自定义路径和名称」窗口。
    - 点击「选择文件」，选中项目的需求文档，例如：  
      `D:\Work\OrderSystem\docs\需求文档.docx`
    - 名称留空则默认使用文件名，也可以自定义为「需求文档」。
3. 第二个按钮用于绑定 UI 设计文件夹：
    - 点击按钮 → 选择文件夹 → 选中：  
      `D:\Work\OrderSystem\UI设计`
    - 名称改为「UI 设计」。
4. 第三个按钮绑定接口文档的在线链接：
    - 点击按钮 → 在路径输入框中直接粘贴 URL：  
      `[https://doc.example.com/order-api](https://doc.example.com/order-api)`
    - 名称设置为「接口文档」。
5. 为了更好区分模块：
    - 右键「需求文档」按钮 → 设置颜色为 **蓝色**。
    - 右键「UI 设计」按钮 → 设置颜色为 **绿色**。
    - 右键「接口文档」按钮 → 设置颜色为 **橙色**。
6. 随着项目资料增多，可以：
    - 使用 **“添加自定义模块”** 添加新行，继续绑定测试报告、上线脚本、打包目录、日志目录等。
    - 使用拖拽将「最常用」的按钮拖到上面几行，减少滚动。
   

从此以后，你只需打开本程序，选中「订单管理系统」项目，点击对应按钮即可快速打开所有相关资料，无需在各个磁盘、浏览器收藏夹中来回查找。

### 使用示例二：个人常用资料与工具面板   

**需求场景**：  
你希望把自己经常用到的 **学习资料、常用软件、网盘链接、常访网站** 整理到一个统一面板，方便每天打开电脑后一键启动。   

### 步骤   
1. 运行程序，在 **“项目管理”** 中新建项目：`日常工作面板`。
2. 将下面这些项目绑定到不同的按钮：
    - 「学习资料」文件夹：
        - 点击按钮 → 选择文件夹：  
          `E:\学习\Python教程`
        - 名称改为「Python 教程」。
    - 「常用软件」：
        - 将桌面上的某软件快捷方式（或 EXE 文件）**直接拖到某个按钮** 上：
            - 比如 `C:\Program Files\Typora\Typora.exe` → 名称改为「Typora」。
    - 「网盘链接」：
        - 点击按钮 → 在路径输入框中粘贴：  
          `[https://pan.baidu.com/s/xxxxx](https://pan.baidu.com/s/xxxxx)`
        - 名称改为「个人网盘」。
    - 「常用网址」：
        - 比如博客、官网、教程网站，直接输 URL 即可。
3. 使用右键 **“设置颜色”** 对按钮进行分组，比如：
    - 学习类资料：统一用 **蓝色**。
    - 工具软件：统一用 **灰色**。
    - 网盘/云服务：统一用 **紫色**。
4. 将最常用的按钮（如「个人网盘」「Typora」「Python 教程」）拖到最上面 2～3 行，以便快速点击。
   

这样，这个项目就变成了一个「个人工作启动面板」，只需启动本程序，选择 `日常工作面板`，手机/浏览器/网盘/编辑器/文档都可以从这里一键打开。

### 常见问题（FAQ）   
- **Q：按钮最少可以有多少个？**  
  A：每个项目默认有 50 个按钮（25 行×2 列），如果删除行后不足 50 个，程序会阻止继续删除，保证至少 50 个。
- **Q：路径变了怎么办？**  
  A：右键按钮 → 选择「重新指定」，重新选择新位置即可。
- **Q：配置文件损坏或想重置配置怎么办？**  
  A：可以先关闭程序，备份当前目录下的 `config.json` 和 `config.json.bak`，然后删除它们重新运行程序获得全新配置；如需恢复旧配置，可把 `.bak` 改名为 `config.json` 再启动程序。
- **Q：能否同时在多个电脑使用？**  
  A：可以将 `jiaoben.py`、`config.json`、`projects` 整个目录一起拷贝，，即可获得同样的界面与配置。
