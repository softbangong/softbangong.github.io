#### 文本处理规则   

**添加前缀**   
- 在”前缀文本”输入框中输入要添加的前缀
- 可选：在”分隔符”输入框中输入分隔符（默认为下划线）
- 示例：原文件名`photo.jpg`，前缀`vacation`，分隔符`_` → `vacation_photo.jpg`
   

**添加后缀**   
- 在”后缀文本”输入框中输入要添加的后缀
- 可选：在”分隔符”输入框中输入分隔符
- 示例：原文件名`photo.jpg`，后缀`2023`，分隔符`_` → `photo_2023.jpg`
   

**替换文本**   
- 在”要查找的文本”输入框中输入要替换的文本
- 在”替换为的文本”输入框中输入新文本
- 示例：原文件名`old_name.txt`，查找`old`，替换`new` → `new_name.txt`
   

**移除文本**   
- 在”要移除的文本”输入框中输入要移除的文本
- 示例：原文件名`backup_file.txt`，移除`backup_` → `file.txt`
   

**移除空格**   
- 无需配置参数，直接应用即可
- 示例：原文件名`my file.txt` → `myfile.txt`
   

**移除特殊字符**   
- 无需配置参数，直接应用即可
- 示例：原文件名`file[@name](https://github.com/name)#.txt` → `filename.txt`
   

**移除数字**   
- 无需配置参数，直接应用即可
- 示例：原文件名`file123.txt` → `file.txt`
   

**移除指定字符**   
- 在”要移除的字符”输入框中输入要移除的字符（多个字符直接输入）
- 示例：原文件名`file-abc.txt`，移除`-` → `fileabc.txt`
   

#### 大小写转换规则   

**转换为大写**   
- 无需配置参数，直接应用即可
- 示例：原文件名`photo.jpg` → `PHOTO.JPG`
   

**转换为小写**   
- 无需配置参数，直接应用即可
- 示例：原文件名`PHOTO.JPG` → `photo.jpg`
   

**首字母大写**   
- 无需配置参数，直接应用即可
- 示例：原文件名`my photo.jpg` → `My Photo.jpg`
   

**驼峰命名**   
- 无需配置参数，直接应用即可
- 示例：原文件名`my_photo.jpg` → `MyPhoto.jpg`
   

**大小写反转**   
- 无需配置参数，直接应用即可
- 示例：原文件名`Photo.jpg` → `pHOTO.JPG`
   

#### 编号添加规则   

**添加序号(前缀)**   
- 在”起始序号”输入框中输入起始数字（默认为1）
- 在”序号位数”输入框中输入数字位数（默认为3）
- 在”分隔符”输入框中输入分隔符（默认为下划线）
- 示例：原文件名`photo.jpg`，起始序号1，位数3，分隔符`_` → `001_photo.jpg`
   

**添加序号(后缀)**   
- 配置方法同上，序号添加在文件名末尾（扩展名前）
- 示例：原文件名`photo.jpg`，起始序号1，位数3，分隔符`_` → `photo_001.jpg`
   

**数字序列**   
- 在”起始序号”输入框中输入起始数字（默认为1）
- 在”序号位数”输入框中输入数字位数（默认为3）
- 示例：原文件名`photo.jpg`，起始序号1，位数3 → `001.jpg`
   

#### 日期处理规则   

**添加日期前缀**   
- 在”日期格式”输入框中输入日期格式（默认为`%Y%m%d`）
- 常用格式：
    - `%Y%m%d`：20231231
    - `%Y-%m-%d`：2023-12-31
    - `%Y年%m月%d日`：2023年12月31日
- 示例：原文件名`photo.jpg`，格式`%Y%m%d` → `20231231_photo.jpg`
   

**添加修改日期**   
- 在”日期格式”输入框中输入日期格式（默认为`%Y%m%d`）
- 在”日期和文件名之间的分隔符”输入框中输入分隔符（默认为下划线）
- 示例：原文件名`photo.jpg`（修改日期为2023-12-31），格式`%Y%m%d` → `20231231_photo.jpg`
   

#### 扩展名处理规则   

**扩展名小写**   
- 无需配置参数，直接应用即可
- 示例：原文件名`photo.JPG` → `photo.jpg`
   

**扩展名大写**   
- 无需配置参数，直接应用即可
- 示例：原文件名`photo.jpg` → `photo.JPG`
   

**删除扩展名**   
- 无需配置参数，直接应用即可
- 示例：原文件名`photo.jpg` → `photo`
   

**替换扩展名**   
- 在”新扩展名”输入框中输入新的扩展名（包含点）
- 示例：原文件名`photo.txt`，新扩展名`.jpg` → `photo.jpg`
   

**只保留扩展名**   
- 无需配置参数，直接应用即可
- 示例：原文件名`photo.jpg` → `.jpg`

### 使用场景示例   

### 场景一：批量整理照片文件名   

**需求**：将一批从相机导出的照片文件名统一格式，添加日期前缀和序号。   

**操作步骤**：   
1. 点击”打开文件夹”按钮，选择照片所在的文件夹
2. 勾选”包含子文件夹”选项（如果照片分布在多个子文件夹中）
3. 在”重命名规则”下拉列表中选择”添加日期前缀”
4. 在”日期格式”输入框中输入`%Y%m%d`
5. 点击”应用规则”按钮
6. 再次在”重命名规则”下拉列表中选择”添加序号(前缀)”
7. 在”起始序号”输入框中输入`1`，在”序号位数”输入框中输入`3`
8. 点击”应用规则”按钮
9. 预览文件列表中的新文件名，确认无误后点击”点击执行重命名”
   

**结果**：   
- 原文件名：`IMG_0001.jpg`、`IMG_0002.jpg`、`IMG_0003.jpg`
- 新文件名：`20231231_001_IMG_0001.jpg`、`20231231_002_IMG_0002.jpg`、`20231231_003_IMG_0003.jpg`
   

### 场景二：统一文档扩展名格式   

**需求**：将一批文档文件的扩展名统一转换为小写格式。   

**操作步骤**：   
1. 点击”打开文件夹”按钮，选择文档所在的文件夹
2. 在”重命名规则”下拉列表中选择”扩展名小写”
3. 点击”应用规则”按钮
4. 预览文件列表中的新文件名，确认无误后点击”点击执行重命名”
   

**结果**：   
- 原文件名：`report.DOCX`、`presentation.PPTX`、`data.XLSX`
- 新文件名：`report.docx`、`presentation.pptx`、`data.xlsx`
   

### 场景三：移除文件名中的多余字符   

**需求**：从一批下载的文件名中移除网站标识和特殊字符。   

**操作步骤**：   
1. 点击”打开文件夹”按钮，选择文件所在的文件夹
2. 在”重命名规则”下拉列表中选择”移除文本”
3. 在”要移除的文本”输入框中输入要移除的网站标识（如`[[www.example.com](https://www.softbangong.top/www.example.com)]`）
4. 点击”应用规则”按钮
5. 再次在”重命名规则”下拉列表中选择”移除特殊字符”
6. 点击”应用规则”按钮
7. 预览文件列表中的新文件名，确认无误后点击”点击执行重命名”
   

**结果**：   
- 原文件名：`[[www.example.com](https://www.softbangong.top/www.example.com)]document#1.pdf`、`[[www.example.com](https://www.softbangong.top/www.example.com)]image@2.jpg`
- 新文件名：`document1.pdf`、`image2.jpg`

### 常见问题解答   

**Q: 重命名后文件无法打开怎么办？**   

A: 这通常是因为文件扩展名被错误修改或删除。请检查文件扩展名是否正确，如果扩展名被删除，可以尝试手动添加正确的扩展名。   

**Q: 如何撤销重命名操作？**   

A: 目前程序不支持批量撤销操作。建议在执行重命名前备份原始文件，或在操作日志中查看重命名记录，手动恢复文件名。   

**Q: 为什么有些文件重命名失败？**   

A: 重命名失败可能有以下原因：   
- 文件正在被其他程序使用
- 目标文件名已存在
- 文件名包含非法字符
- 文件路径过长
   

请查看操作日志中的错误信息，根据具体原因进行处理。   

**Q: 可以同时应用多个规则吗？**   

A: 建议逐步操作   

**Q: 程序支持哪些文件类型？**   

A: 程序支持所有类型的文件，包括图片、视频、音频、文档、代码、压缩包等。文件类型识别基于文件扩展名。   

**Q: 如何处理大量文件？**   

A: 程序支持批量处理大量文件，但建议分批处理（如每次处理1000个文件），以避免内存占用过高。使用”包含子文件夹”选项时要谨慎，避免意外处理过多文件。
